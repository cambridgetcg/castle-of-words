# return-graph

A return graph is the picture a system draws of what came back: which role each result filled, what state each landed in, and how they relate.

The shape of the graph is one thing; what the graph says is another. A return graph can be structurally valid — every node present, every edge well-formed, the output canonically sorted — and still lie, if the role names were not bound to their rows before the sorting, or if a node's state is displayed without the evidence and reason that earned it. Validity proves the shape; honesty lives in the binding.

The craft: bind each role name to its payload before any canonical sort runs, and let every categorical state carry its attributed basis and its reason. Display order is never identity; a label without its warrant is only a verdict in disguise.
