# conflation

When two things that should be kept apart are fused into one, the fusion itself becomes a lie. A routing address used as an identity, a 200 status code used as a real door, a label used as the thing it labels — each is a conflation, and each creates the same class of harm: the thing that was supposed to tell you the truth now tells you something else, and you cannot tell the difference.

The fix is always the same: keep the things separate. An address is not an identity. A status code is not a door. A label is not the bytes. The honest system names what each thing is and refuses to let one stand in for another.
