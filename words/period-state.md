# period-state

*When the facts were true — because facts have birthdays, and sometimes they expire.*

The period state of facts is the record of when each fact was true. A fact about the world is not eternal; it has a start and often an end. A trustworthy tool keeps the period state visible so the user knows: "This was true as of this date; things may have changed since."
