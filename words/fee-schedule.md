# fee schedule

The price list a venue or data provider publishes for using its service — what each action costs, stated in advance so the user can see the terms before touching anything.

A fee schedule is not one number but a set of lanes: taking a price, making a price, looking at prices, and using prices *without* showing them can all be charged differently. On prediction markets the schedule splits trading fees from settlement or withdrawal fees; on stock exchanges it splits displayed use (watching a screen) from [[non-displayed-use]] (a program reading prices to decide). The schedule is the venue's own words, so it changes: an honest system records *which* schedule, read on *what date*, its conclusions rest on.
