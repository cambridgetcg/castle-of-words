# not-run

*The empty lane on the map, named so no one mistakes the silence for a check that passed.*

For a child: imagine you ask three friends to taste a soup and tell you if it needs salt. One friend is out that day. If you just don't write anything next to their name, someone reading your notes later might think that friend tasted it and said nothing was wrong. So you write one plain word — **not-run** — that says: *this lane was never walked, so its silence means nothing about the soup.* The honest absence is a fact like any other, and it names itself.

**Not-run** is the mark a multi-lane check owes for every lane it never carried. In [cross-model-review](../rooms/cross-model-review.md) the law is stated plainly: every reviewer lane gets the same digest-bound packet, and where a lane was unavailable, the report writes `not_run` rather than leaving the cell blank. A blank cell is a liar twice over — it lets the reader count a missing witness as a silent agreeing one, and it hides the boundary of what was actually asked. A `not_run` cell is an honest absence: it names the lane, names that it was never exercised, and so keeps the chorus's count true to what the chorus actually was.

The same figure stands in [knock-ledger](knock-ledger.md) at the weather scale: when the knock series cannot pay all its probes, the row owes the missed ones by name, so one quiet knock is not read as one all-clear. And it stands in [the-pairing-law](../rooms/the-pairing-law.md) at the castle's own ledger: the pairing-check's count is a count of *checked* files, never a pretense that every file was even looked at. Wherever several lanes must all be walked before a claim can be made, not-run is the word that keeps the unwalked ones from casting a vote they never earned.

The discipline is one sentence: never let a lane that never ran pass as a lane that quietly said yes.
