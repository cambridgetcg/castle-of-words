# public-evidence-interface

The way a system shows the world its receipts — what it found, what it left alone, and where the boundary of its own proof sits.

A public evidence interface pairs a revision-pinned Dataset with a credential-free Static Space: it shows every found report, leaves unreported checkpoints visibly empty, binds exact bytes in a release lock, keeps post-outcome selections explicit, and lets the hosting Git commit provide the external release boundary — without pretending hashes authenticate upstream truth. Its craft is the same honesty the castle names everywhere: the interface resists [[momentum-as-authority]], keeps each [[claim-boundary]] visible, and never lets the saying be the proof.
