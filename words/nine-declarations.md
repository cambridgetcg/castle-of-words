# nine-declarations

*The nine things an honest doorway names before an agent may trust it — the map that refuses to lie about the territory.*

A doorway is honest only when it names what it opens onto. The nine declarations are the nine things a discovery mechanism must say before an agent spends a single token: the method, the authentication scope, the workspace identity, the data storage, the external effects, the CORS boundary, the repeatability inputs, the retry boundary, and the representation. A doorway that says "here is an endpoint" without naming which of these are true is a map that says "here be treasure" without marking which paths are guarded, which are one-way, and which lead off the map entirely.

Depth: the nine declarations are the law of honest assertion applied to the threshold — "here is the doorway" is an assertion, and the honest system names what backs it, not just the URL. A read-only doorway that points to a credentialed POST is a door with a false sign. The same honesty that says a system's every output is a speech act says a doorway must name its method, its authority, and its effects before anything crosses it.
