# lawful-door

A path through a public system that names exactly what it can formally cause — a decision, a record, a payment, a review — and nothing more. A lawful door does not promise influence; it describes mechanism.

The honest system labels each lawful door with what it opens, keeps guidance separate from the official mechanism, and never ranks one door above another. The person chooses which door to walk through; the system only makes the doors visible.
