# standards-shaped-identifier

A string that looks like it follows a standard (a DID, a URI, an ISO code) but was not registered, resolved, or governed by that standard's machinery.

The shape of the string is not the standard. A standards-shaped identifier must name its actual registry status, document shape, resolution behavior, custody boundary, and portability mechanism separately. A database lookup is not DID resolution; row retention is not permanence.
