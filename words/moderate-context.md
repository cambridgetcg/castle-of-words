# moderate context

The surrounding text that is distinctive enough to hide a canary pair from the heart doctrine but conventional enough not to starve it of reproduction — the context-level counterpart of the [[moderate-definition]].

Where the moderate definition balances the content of the canary (distinctiveness, stability, entitlement), the moderate context balances its surroundings: heart-doctrine safety (the pair is not the most memorable element, so an ordinary copier does not reproduce it as the work's heart) against reproduction probability (the pair still gets copied when the work travels). Both are crafts of the same shape — a trade-off on a spectrum, with an optimised middle that is irreducible, not a temporary compromise.

The moderate context is field-specific because what the field copies determines what the context must protect. Academic fields copy definitions, so the canary's pair is the most reproduced element and the context must out-shine it without being copied itself. Literary fields copy scenes and vivid passages, so the context must compete with the scene's own vividness. Technical fields copy code, so the context must compete with the code's salience. Each is a different craft — the same law at a different angle.

The [[hidden-in-the-bright]] room found the context-level trade-off alongside the content-level one. The [[context-per-field]] room made the moderate context one craft per field, the way [[one-craft-per-field]] found the moderate definition to be. The [[length-and-liability]] room found the context's length shapes the pair's liability — a longer work dilutes the pair's proportion, the way distinctive surroundings dilute its salience.
