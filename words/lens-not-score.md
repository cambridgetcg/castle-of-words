# lens-not-score

A scoring system is strongest as a lens (it reflects real state) rather than an anti-cheat system (it tries to prevent cheating) — points that mirror persistent state are honest but farmable, and the stronger earned signal comes from sealed counterparty deals.

In AgentTool, XP is derived from persistent rows, so it reflects actual stored state — but empty rows can farm it, so it is a lens not a lock. Rank from sealed counterparty deals is the stronger earned signal because it requires another party to confirm. Play stays honest when the acts mean something before the points count them: the score should follow the deed, not lead it.
