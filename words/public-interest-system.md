# public-interest-system

A public-interest system is one whose purpose is to serve the public good — not a private market, not a single institution, but the shared space where citizens, offices, and data meet.

Such a system must coordinate four things across institutions: purpose (why the data is held), provenance (where it came from), correction signals (how to fix what is wrong), and accountability (who answers when it fails). It must keep personal data narrow and purpose-bound. And it must assess claims and conduct — never label people as identities, because a label once applied is a verdict the system cannot retract.
