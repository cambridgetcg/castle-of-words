# smoke-test

A smoke test is a quick probe that asks: does the thing that just deployed still work? It is not a full test suite — it is the first breath after a change, the minimum check that says the system is alive enough to let the next step proceed.

In an ordered release rail, the smoke test is the gate between the API deploy and the frontend deploy. A passing smoke test is the only permission the frontend needs.
