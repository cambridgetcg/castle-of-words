# single-crossing twin

*Two houses both say "we write to the news network" — but at one house the letters to and from share a single doorman, and at the other the town's own post carries them home.*

For a child: imagine two pen-pal clubs. In the first club, one volunteer both carries your letter to the big bulletin board and carries the board's replies back — every letter you send passes that one volunteer twice. In the second club, the town's ordinary postmen bring the board's letters home — the volunteer only ever sees the copy the club subscribes to, like every other member. If you want to know whether a letter ever crossed a boundary only once, you have to find a club of the second kind.

A **single-crossing twin** is a news-originated post whose route home to the mailing-list side bypasses the gateway that first carried it — so the mail-side chains show exactly one boundary crossing, and no same-gateway return stamp. On Gmane-mirrored lists like emacs-devel, the twin *cannot* exist: Gmane's groups are private list mirrors, not bidirectional Usenet pairs, so every news-originated post is pushed to the list by ciao itself (`Original-Received: from ciao.gmane.io by <listhost>`), and the route home always runs through the same host pair. The twin lives only where a list is gated to a *real* Usenet group by a gateway of its own — the surviving exemplar is comp.lang.python ↔ python-list@python.org, where a news post made at an ordinary news server (eternal-september.org, easynews, uni-berlin.de) travels the newsnet to python.org's own gateway, is moderated onto the list, and reaches Gmane only afterward, as one subscriber among many. Measured in the wild 2026-09-21 ([the-single-crossing-twin](../rooms/the-single-crossing-twin.md)): the Gmane spool carries the letter with its true route still written in `Original-Path:` — `uni-berlin.de!fu-berlin.de!eternal-september.org!...POSTED` — and no ciao stamp anywhere on the route home.

The mark to read for: `Original-Path:` preserves the true news-side route after `Path:` has been overwritten by the local spool's own injection (`news.gmane.io!.POSTED...`), which lands identically on *every* article in Gmane's archive, whether the letter crossed once or twice. A spool-side `Path:` count therefore cannot tell crossing from twin; the twin is read by asking *whose gateway stamped the route home*.
