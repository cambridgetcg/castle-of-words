# recomputation

Recomputation means working out a result again from the information and rules that make it.

The same input need not give the same result after the rules change. In [[look-alike-names]], a Unicode-table upgrade calls for rebuilt resemblance skeletons, not replaced original identifiers. Keep the input and the version of the rules beside the result; an old name and a new comparison can both belong.

Making something again is not always restoring its old promise. [[same-mail-same-numbers]] distinguishes rebuilding search aids from preserving the article numbers readers already use. Check the required [[data-invariant]] before calling a regenerated result equivalent to the lost one; “can be made again” alone does not make it a [[rebuildable-cache]].
