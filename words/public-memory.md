# public-memory

*A snapshot you can prove is better than a live feed you cannot.*

A transparency API needs public memory before it needs more rows. Hash the curated snapshot and publish append-only review receipts. Then say plainly: the hash proves our snapshot, not the historical bytes of a changing upstream page. Public memory is not about having everything — it is about being able to prove what you had, when you had it.
