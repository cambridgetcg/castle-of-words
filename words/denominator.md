# denominator

The number that says out of how many — the whole counted group a part is measured against, so a count of something can never be mistaken for a count of everything.

A map, a coverage report, or a score that shows only the numerator — the hits, the found, the mapped — hides whom it never asked. A visible denominator names the *universe*: the exact, source-defined set the count was drawn from. Then "missing" can be honest — a place not yet reached — instead of silently reading as zero. The [[coverage]] truths lean on it ("missing is unmapped, never zero"), and so does every honest percentage: a share without its denominator is a fraction with no bottom, a number that cannot be checked.
