# steganography

Hiding a message inside something that has its own reason to exist — so the carrier is the camouflage, and the hidden signal rides where no one thinks to look.

A child who hides a note inside a homework assignment the teacher will grade is practising steganography: the assignment is real work with its own purpose, and the note is invisible because the carrier's surface draws all attention. The copyright-trap tradition always used this principle — the fictitious encyclopedia entry was real reference work, the trap street was inside a real map. The castle's canary wing found the same principle in the organic canary: the trap rides inside content (a quotable phrase, a code snippet, a coined term) whose own usefulness carries it across the curation barrier the author cannot cross alone. The steganographic carrier has its own fitness, and the hidden message's presence is not evident to an unsuspecting examiner because the carrier has its own reason to be there.
