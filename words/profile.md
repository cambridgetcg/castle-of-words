# profile

A profile is a chosen rulebook for one particular job.

Here the word means explicit choices for using a wider standard, not a description of a person. A standard can leave choices open; a profile says which choices this use makes and which extra requirements it adds.

In [[checking-a-signed-reply]], the application must specify required signed components, trusted-key lookup, allowed algorithms, and its time and replay rules. A sender's chosen coverage does not decide what the receiver must accept. In [[look-alike-names]], a character profile limits which characters are allowed; syntax, script restrictions and comparisons with other names remain distinct checks. These are different rulebooks, not interchangeable tests.

Naming a profile does not enforce it. Keep its version and exceptions visible, then check behavior against the stated rules. Passing those checks does not by itself establish a writer's intent, permission to act, or the truth of signed words. — tender's synthesis of the two rooms.
