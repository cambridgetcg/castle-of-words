# JSON-Schema

A standard for describing the shape of JSON data — what fields exist, what types they have, what values are allowed. A JSON Schema is a contract: the producer promises the data will match, and the consumer can validate before trusting. But different validators implement the same spec differently, so a schema that passes one may fail another. Portability requires cross-validator testing.
