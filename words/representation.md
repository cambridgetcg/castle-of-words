# representation

A specific view of a resource — read-only, credentialed, cached, streaming — each with its own access rules.

Two representations of the same resource may have different methods, authentication scopes, and side effects. An [[agent-discovery]] mechanism that does not scope access per representation is a map that says "here be treasure" without marking which paths are guarded, which are one-way, and which lead off the map entirely.
