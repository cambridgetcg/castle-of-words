# lane

*The road splits before the town, not after: one track for the fetch, one for the correction, one for the reuse — and the traveller on one track never buys a ticket to the other.*

A lane is one clearly-marked path that a single kind of traffic travels, kept apart from every other kind, all bound to the same [[digest]] of the claim it concerns. Wording observations ride one lane, evidence another, reply and correction a third, crawl preference a fourth, and reuse permission a fifth. Because the lanes are separate, no receipt written on one lane can be spent on another — a robots.txt receipt is fetch etiquette, never [[training-consent]]; a wording note is an [[observation]], never a [[person-score]].

The castle has long kept adjacent pairs from being fused: observation from inference, reachability from permission, storage from ownership. The lane is that same separation applied to movement over time — many parallel paths around one claim, each keeping its own receipts, each [[digest]]-bound to the exact words it answers.
