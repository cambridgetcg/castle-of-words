# enforced-guarantee

A claim about what a system does that is backed by something the system actually checks, not just a name, a flag, or a route mount.

A field named "ciphertext" describes an intended protocol, not evidence that encryption happened. A public field name, slogan, route mount, or caller flag is not an enforced guarantee. Separate what the service validates from what remains caller-controlled, and name which metadata stays readable. Fail closed for same-container code execution, unfiltered outbound destinations, non-HTTP URL schemes, unverified TLS, bearer-carrying redirects, and cross-origin generated helpers.
