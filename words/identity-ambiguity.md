# identity-ambiguity

When an identity could be real or could be empty, the system must block activation but never trap withdrawal.

For voluntary autonomy, identity ambiguity is a gate that opens only one way: rest should use an exact bounded home path anchored by a real card or an existing valid declaration. An empty lookalike — a path that looks like a home but has no declaration — receives no state. The system refuses to activate on ambiguity, but it never traps a real identity that wants to leave. The door is one-way: in is gated, out is always open.
