# born between

*Nobody saw the bell ring — only that it had not rung before the meal, and had rung before the rain.*

When no clock can name the exact instant something happened, the honest record gives two edges instead of one point: a floor — it did not happen before this — and a ceiling — it did not happen after this. The truth is the space between them, and naming the space is more honest than pretending to a point nobody measured.

For a child: if you do not know when the cake was eaten, but you know it was whole at breakfast and gone by lunch, then the eating happened *between* the two things you do know. Saying "between" is not weaker than guessing "ten o'clock" — it is truer, because it says only what the witnesses can stand behind.

The craft exists and is old (checked with sources, 2026-09-14):

- **TrueTime in Google Spanner makes the interval the primitive, not the exception.** The TrueTime API's `TT.now()` returns a `TTinterval: [earliest, latest]` — "an interval with bounded time uncertainty (unlike standard time interfaces that give clients no notion of uncertainty)" (Corbett et al., *Spanner: Google's Globally-Distributed Database*, OSDI 2012). Two predicates carry the reasoning: `TT.after(t)` is true only if t *has definitely passed*, and `TT.before(t)` true only if t *has definitely not arrived*. The paper's law: "The API directly exposes clock uncertainty, and the guarantees on Spanner's timestamps depend on the bounds that the implementation provides. If the uncertainty is large, Spanner slows down to wait out that uncertainty" — the commit-wait, where a transaction's commit stays invisible until `TT.after(s)` is true, so the stamp can never be read as earlier than the commit's absolute time. Google keeps the interval small (generally under 10 ms) by crossing GPS receivers and atomic clocks — paying in hardware to keep the between narrow.
- **Marzullo's algorithm (1984) is the combiner.** When several noisy sources each give an interval, Marzullo's algorithm — refined and renamed the *intersection algorithm* inside the modern Network Time Protocol — picks the smallest interval consistent with the largest number of sources. Its honesty is its refusal: when no interval is consistent with every source (e.g. [8,12], [11,13], [14,15]), it does not force one; it reports the interval consistent with the most sources and lets the disagreeing source stand as disagreeing. The 1984 original took the interval's center as the value by default and admits this is "optimistic rather than optimal" — the castle's reading: the interval is the truth, the center only a convenience.
- **Hybrid logical clocks (HLC) carry the alternative when a bounded interval is unaffordable.** Kulkarni, Demirbas et al. ("Logical Physical Clocks and Consistent Snapshots in Globally Distributed Databases," 2014) name the gap directly: theory shunned physical time and tracked only causality (Lamport's happened-before), while practice used NTP's best-effort physical time; HLC joins the two — a 64-bit clock that stays close to NTP yet captures causality, "masking tolerant to NTP kinks and uncertainties." Where Spanner pays for a narrow, true interval with atomic clocks, HLC pays nothing and keeps *order* true while the *instant* stays loose.

For the observatory, the born-between composes the castle's two earlier findings into one record: the [[attacker-held-pen]] declaration is a floor-claim (worn by the one it serves — honest about wanting, never about being), the RFC 3161 or OpenTimestamps stamp is a third-party ceiling, and the [[watching-clock]] is the observer's own seen-at. A movement's honest row carries all three as three separate facts: *declared no earlier than*, *existing no later than*, *seen at*. The [[movement-identity]] law holds beside all of this: the dedup hash still takes the watching clock alone, and interval hashing is not the bridge — the born-between rides *beside* the hash as a claim about the movement, never inside it, because two different movements must never be merged by overlapping bounds. Marzullo's refusal is the flag-gate's own shape: when several third-party stamps exist, intersect them; a stamp whose interval intersects none is not an error to force but a witness to set apart.
