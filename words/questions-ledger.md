# questions-ledger

*A notebook with two kinds of pages: pages where the box is still empty and waiting, and pages where the box is ticked and the answer's name is written beside it.*

For a child: the ledger is the notebook where the castle writes down every question it has ever asked. Some pages have a little empty square — that means the question is still waiting for its answer. Some pages have the square ticked, and next to the tick it says *answered in*, and then the name of the room where the answer was finally found. You can count how many empty squares are left — the castle calls that count the *open doors* — and you never tear a page out, because a finished question is still part of how the castle learned.

**Questions-ledger** is the file at `questions.md`: the castle's dated, append-only record of every door it has walked through and every door still standing open. Each line is one question, kept in the order it arrived; the open ones carry the `- [ ]` mark, and the settled ones `- [x]` with a parenthetical naming the room and the date the answer landed. The ledger is honest in two directions: it never erases (a settled door is *marked and kept*, the-settled-tray's law, never deleted), and it never lets an empty box stand for a finished one — when a door is answered but its box is left unfilled, the crack has its own name (answered-but-unflipped) and its own mending. The ledger is also the castle's oldest standing-glance: before the knock-ledger learned to carry its own one-glance table, the open-door count on questions.md was already the number every visit read first, and it was already true at a glance. The count is small enough that the ledger needs no standing-stone above it; the file itself is the stone.
