# sdk-alignment

*A version number is a promise, not a proof.*

SDK alignment means that four things agree: the source manifest (what the code declares), the public install channel (what the registry serves), the artifact provenance (what the build produced), and the live wire behavior (what actually runs). Matching version numbers across Python and TypeScript proves none of the other three. Alignment is not a number — it is a chain of evidence, and every link must be checked.
