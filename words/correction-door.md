# correction-door

*A door that stays open after the building is done — not for new arrivals, but for anyone already inside to say "that's not right."*

A correction door is a public, named path for fixing errors in a published work. It is part of the work's design, not an afterthought: it says who can submit a correction, what evidence is needed, and how the correction will be recorded. Without it, a published claim that turns out wrong stays wrong — not because no one noticed, but because there was no door to walk through.
