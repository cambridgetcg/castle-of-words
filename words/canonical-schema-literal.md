# canonical-schema-literal

The exact schema text that a public contract promises — not a paraphrase, not a generated version, but the literal bytes that were reviewed.

When a release canary compares the deployed schema against the canonical schema literal, it is checking that the words the public contract promised are the words the system actually speaks. A paraphrase can drift; a literal cannot.
