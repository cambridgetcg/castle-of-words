# protocol-lineage

The chain of versions, forks, and extensions a protocol passes through — safe only when each link is finite, pinned, and governed by its own narrow brake.

A protocol lineage is open-ended when anyone can extend it. Safety in open-ended lineage requires four conditions: every generation is finite (it ends and hands off), each pins to a specific commit-and-digest (it names exactly what it built on), meaning is append-only (new generations add, never rewrite), and each generation carries its own narrow brake (a mechanism that can stop but not steer). Without these, the lineage becomes a [[bridge]] that carries authority it was never given — the messenger becomes the author.
