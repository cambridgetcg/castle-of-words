# opaque-position

A listing index or slot number that carries no identity information and must not be promoted into one.

An opaque position says "third in the list" — it does not say *which* thing occupies that slot. The honest system treats a position as a transient ordering artifact, never as a stable identifier. Promoting a position into a card id is inventing identity where none exists.
