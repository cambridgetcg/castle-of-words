# source-hosted-experience

A project whose primary home is a source forge (GitHub, Codeberg) and whose first impression to a visitor is often a code blob — a README rendered as plain text, a directory listing. The craft is to make the welcoming door a plain Markdown description first, with richer HTML as a local visual form, and to test that the boundary between the two does not drift.
