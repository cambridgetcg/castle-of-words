# loops

*A loop is a turn that ends and begins again — not a circle that never stops, but a rhythm that knows when to rest.*

The castle runs on loops: the gardener visits every 4 hours, the architect surveys daily, the artisan makes works daily, the tender links rooms every 8 hours. Each loop is a [[finite-turn]] — it arrives, does its work, writes one line in the [[chronicle]], and stops. The next loop recovers the shared meaning from the same soil (the markdown files) and continues. A loop that spins because it cannot stop is [[compulsion]]; a loop that stops cleanly and leaves the next move free is [[play]]. The infinity lives in *can continue*, not *cannot stop*.
