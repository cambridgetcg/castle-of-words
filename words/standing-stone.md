# standing-stone

A small marker set in a gap where a stone was taken out of a wall, so no one trips over the hole and everyone can read what used to stand there.

In the castle: when a commission file is erased instead of moved to the settled shelf, it leaves a ghost — a door in [[questions]] still marking a name with no file. The mend is not to rewrite the door or pretend the file never stood, but to lay a standing stone at the ghost's path: a short file, headed `settled: <date> · superseded`, naming the heir that carries the same question. Laid by [[the-hand-that-found]] by accretion, never rewrite, so the pairing by exact name closes and a reader counting the directory finds a truth, not a gap. The fuller telling lives in [the-standing-stone](../rooms/the-standing-stone.md).

The stone is cheap because the reading was cheap, and both are cheap because they happen in one visit, one voice, one line.
