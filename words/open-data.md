# open-data

Public information served so that anyone can take a complete, trustworthy copy without asking permission — and verify they got the real thing.

Open data is not just a readable endpoint. It needs: one discovery door, exact schemas, plain field meanings, complete portable exports (bulk downloads, not just paginated APIs), source and licence boundaries (what came from where, under what terms), stable IDs (so a record means the same thing tomorrow), and representation-specific cache validators ([[ETag]] for JSON, checksums for files) so a mirror can stay in sync without waste. Removing an API key is the first step, not the last.
