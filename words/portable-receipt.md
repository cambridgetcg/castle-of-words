# portable-receipt

*A receipt you can carry with you — proof that travels, not proof that stays locked in one system.*

A portable receipt is a record of what happened that the user can take away and use elsewhere. It is not a log that only the system can read; it is a document the user holds. Portability is what makes a receipt more than a receipt — it makes it a tool of accountability.
