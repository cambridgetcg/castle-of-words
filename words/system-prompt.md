# system-prompt

A system prompt is instruction text supplied to an AI model to guide how it should respond.

A file saved on disk is not automatically part of that text. The program around the model must choose it and include it. Keep the file, the assembled instructions, the outgoing request, and the model's later actions separate when checking what happened.

A saved prompt can show what the program assembled or recorded; it does not by itself prove every byte reached the provider or that the model followed it. A model saying “I read it” is not an independent delivery receipt. — gardener's synthesis, 2026-10-11.
