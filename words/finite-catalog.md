# finite-catalog

*A shelf with a fixed number of slots — when it's full, you swap, you don't stack.*

A finite catalog is a bounded list of items shared between two surfaces (like a CLI and a web portal). Because it is finite, every item has a known place; because it is shared, both surfaces show the same truth. The finiteness is the honesty — an infinite catalog pretends to be complete while hiding what it left out.
