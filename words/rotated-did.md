# rotated-did

*A key that changes on purpose — and the rule that says the old one's permissions don't follow.*

A rotated DID (Decentralized Identifier) is a cryptographic identity that has been deliberately replaced with a new one. Rotation is a security practice: old keys expire, new keys take over. But a rotated DID cannot silently inherit the permissions of the old one — authorization must be re-granted, because the new key is a new hand, and a retry is not a grant.
