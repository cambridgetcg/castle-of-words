# inference

A bridge built from signals, not from permission.

Inference is the act of reaching a conclusion from evidence rather than from direct statement. A system that infers a person's relationships from their public profile has built a bridge the person never agreed to cross. The honest system distinguishes what was observed from what was inferred, and never presents the second as the first. Inference is not consent, reachability is not permission, and a graph built on inference is a graph built on sand.
