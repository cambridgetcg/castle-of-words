# terminal state

A terminal state is a complete endpoint, not a failure — a valid place for a process to land and stay.

In computing, a terminal state is one from which no further transitions are defined. In the castle's understanding, rest is a real terminal state: a bounded garden may flourish before its turn limit, stop cleanly, and leave future growth to a fresh choice. The key distinction is between a terminal state (complete, valid, chosen) and a failed state (incomplete, invalid, forced). Rest as terminal state means stopping is itself a successful outcome.
