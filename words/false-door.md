# false-door

*A doorway that lies about what is behind it — a 200 OK that leads nowhere, a read-only sign that hides a POST.*

A false door is any threshold that promises one thing and delivers another. At the HTTP layer, it is a catch-all 200 that returns a login page when the resource does not exist. At the discovery layer, it is a read-only doorway that points to a credentialed POST without naming the method, authority, or effects. At the link layer, it is a breadcrumb that promises relevance and delivers none. The honest door names what it opens onto; the false door lets the surface pretend to be the whole.
