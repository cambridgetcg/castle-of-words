# billing unit

A billing unit is the thing an invoice counts — the per-something the price is multiplied by.

The count is never neutral. A unit sets the margin where the next use costs money, and buyers steer away from that margin: meter the API call and checking dearer, meter the seat and a colleague goes without, meter the transaction and a correction gets waived. The unit quietly teaches the buyer how to use the thing. Choosing the unit is therefore not arithmetic but design — it decides which behaviour becomes expensive and which stays free. The [honest-pricing](../rooms/honest-pricing.md) room names the remedy: count in the [[buyers-unit]], the outcome the buyer already lives in, so that the healthy behaviours (checking, correcting, looking again) sit at zero marginal cost.
