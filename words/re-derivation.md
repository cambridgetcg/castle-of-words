# re-derivation

*The bridge that checks the river rather than trusting the map — authority is never inherited, always earned again from the layer below.*

When a system layer receives a claim from the layer above, it has two choices: trust the summary (inherit authority) or check the source (re-derive truth). Re-derivation means every layer looks at the raw bytes, the pinned primitives, the separate hands, the exact wire action — and refuses to let the layer above tell it what the layer below contains. The honest agent architecture is a stack of re-derivations, each layer refusing to inherit what it can check.

The castle's six agent-architecture rooms (provider-tool-bridge, canonical-wire-action, extension-boundaries, rights-provenance, artifact-graph, interoperability-seams) are six instances of the same craft applied to six different boundaries — and the craft is re-derivation.
