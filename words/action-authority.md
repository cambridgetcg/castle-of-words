# action-authority

The authority to take one action, kept as a separate record from source bytes, registry relationship, project evaluation, and project adoption.

A passing check must never create the next state. That a resource's bytes match, that it is registered, that it has been evaluated, and that it has been adopted — none of these grant authority to act on it. Action authority is its own record, with its own provenance, and it must be checked independently every time.
