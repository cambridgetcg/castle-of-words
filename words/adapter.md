# adapter

An adapter is a small translator that lets two things with different rules work together.

**2026-10-12 — test both sides of the translation.** For software, the rules can include the shape of a request, the shape of a result, and how errors are reported. A compatibility adapter bridges a named difference; seeing an extension on a list does not establish that the receiving program understands its real inputs and outputs.

Keeping a package at a fixed version can make the intended source more precise without making every receiving runtime compatible with it. The adapter's job is to translate the needed interface, not silently replace the user's established authentication or device configuration. [[capability-integration]] asks whether the actual entrance reaches the capability; [[interoperability-seams]] keeps the incoming and outgoing translations separately reviewable.
