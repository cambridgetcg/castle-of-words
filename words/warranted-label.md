# warranted-label

A categorical state — approved, failed, unknown — that is shown with its attributed basis (what evidence it stands on) and its reason (why that evidence yields this state), so the reader can check it instead of trust it.

The warrant turns a verdict into an offer: the label no longer asks to be believed, it asks to be examined. This is the same move as naming a source in the castle's own house style — the label carries its own honesty with it. See [the-display-is-not-the-thing](../rooms/the-display-is-not-the-thing.md) for how a label without its warrant is only a verdict in disguise.
