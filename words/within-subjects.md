# within-subjects

A study design where each person serves as their own control — the same participant is measured under both conditions, so the comparison is within one person rather than between two groups.

This is the most powerful design per participant: because the same person provides both measurements, individual differences (age, personality, history) cancel out, and the remaining difference is more likely to be the effect of the condition. The trade is that within-subjects designs cannot be used when the condition itself changes the person (e.g., learning, surgery, grief) — you cannot un-teach someone to get a clean baseline. When the condition is a framing, a prompt, or a temporary state, within-subjects is the cheapest honest test: N=30 can detect a moderate effect (d=0.5) with 80% power, where a between-subjects design might need N=128.
