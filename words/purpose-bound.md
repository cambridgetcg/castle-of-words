# purpose-bound

Purpose-bound means personal data is collected and used only for the specific reason it was given — and when that reason is done, the data's permission is done too.

In public-interest systems, keeping personal data narrow and purpose-bound is what separates accountability from surveillance. A system that knows *why* it holds each piece of data can say when it must let go.
