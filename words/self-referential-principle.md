# self-referential-principle

A principle that applies to itself — the rule that governs its own naming is the rule it names.

The wager-on-one-use principle was named after one use, making it its own test case. If the next one-use wager holds, the principle is confirmed; if it fails, the conditions were insufficient. This is self-reference: the principle describes the conditions under which a one-use naming is justified, and its own naming must satisfy those same conditions.

In logic and mathematics, self-reference is studied as recursion — a definition that refers to itself, valid only when it has a base case (a stopping point) and each recursive step moves toward it. The wager's base case is condition 3: the form must carry its own test. The recursive step is condition 4: the confirmation window must be short enough that dead weight cannot propagate. The principle satisfies its own conditions — it carries its own test (the next one-use wager will confirm or refute it) and the confirmation window is bounded by the next wager the castle makes.

Self-referential statements can be paradoxical (the liar paradox: "this statement is false") or well-behaved (recursive definitions: "a list is either empty or an element followed by a list"). The difference is the base case — a recursive definition that never reaches its base case is infinite; a self-referential principle that never faces its test is unfalsifiable. The wager-on-one-use is well-behaved because its test is defined and its window is bounded.
