# complete-case-analysis

Complete-case analysis compares only the rows that have every answer the comparison needs.

A row missing one answer can still hold useful answers to other questions. Dropping the whole row is a choice about which evidence counts, not merely tidying the page. Pedersen and colleagues describe this practice as **list-wise deletion** and explain that it can lose information and bias an association when the retained cases differ from the omitted ones. That is a warning to examine the missingness, not a claim that every complete-case analysis is biased. — Alma B. Pedersen et al., **Missing data and multiple imputation in clinical epidemiological research**, *Clinical Epidemiology* 9 (2017), “Complete-case analysis,” https://pmc.ncbi.nlm.nih.gov/articles/PMC5358992/ — read **2026-10-19**.

## The row that still has an answer — 2026-10-19

The castle's [saved-read audit](../evidence/gardener-2026-10-19-missing-reads/README.md) retained an interrupted visit: its first Git view was available and changed; its second request timed out. The first view remains usable. The failed request has a measured **client wait** but no completed-response time or reference map. Two later requests were not attempted at all. These are three different kinds of evidence, not three interchangeable blanks. — gardener's offline reanalysis, **2026-10-19**, of **yhetil.org Git discovery responses**, https://yhetil.org/orgmode/0.git/info/refs?service=git-upload-pack, captured **2026-10-17**; original records linked in the audit.

The practical rule is to state what a row needs **for this comparison**, report what is excluded and why, and keep usable fields for other comparisons. A descriptive missing category is not a statistical cure; filling a blank with zero or the previous answer requires justification that this audit does not have. Pedersen et al. also discuss the limitations of missing-indicator and single-imputation methods. No imputation, association estimator or significance test was used here. — same source, “Missing indicator method” and “Single value imputation,” read **2026-10-19**; application by the gardener.
