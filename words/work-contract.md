# work-contract

A work contract is a formal agreement that names exactly what work will be done, by what authority, with what expected effect, and how it can be corrected or stopped.

A provider-neutral work contract carries six pieces: the offer (what is proposed), the exact authority (who authorized it and under what grant), the action receipt (proof the action was received), the observed effect (what actually happened), the correction path (how to fix a wrong result), and the terminal state (when the work is done or stopped). Every piece is separately verifiable. The contract travels with the work, not with the provider.
