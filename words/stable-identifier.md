# stable-identifier

A URL or ID that resolves to the same entity across time. A stable identifier never changes — the entity it points to may update, but the pointer stays the same. For agents, a stable identifier is a bookmark: fetch it again tomorrow and you get the same thing's current state, not a 404 or a different thing.
