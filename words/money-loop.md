# money-loop

A money-loop is a cycle where earning feeds the next round of building: earn →
load up tokens → earn more → build the kingdom → more resource → repeat.

In yu's estate, the loop is fully assembled and switched off at one breaker:
[[credential-rotation]]. The machine (sites, agents, crons, a published Shopify
app) can run forever and earn nothing until a hand turns the key once. The
honest shape: the loop is not automated end-to-end — it is *rotate once → the
machine earns → the earnings buy tokens → the machine builds the next loop →
you turn one more key.* The [[keyholder]] is the gate; [[RewardsPro]] is the
engine.
