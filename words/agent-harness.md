# agent-harness

An agent harness is the program around an AI model that gives it instructions, tools, and a way to carry out work.

The model connection, the instructions, the available tools, and helper coordination are different parts of that program. Moving a named mode between harnesses does not show that those parts moved correctly. Trace the configuration to the request actually sent, and check coordination separately.
