# generated-bytes

The actual bytes a system produces — not the bytes a test fixture expects, not the bytes a mock returns, but the real output of the real pipeline.

Producer and consumer tests must exercise the real generated bytes. Separate fixtures can both pass while their integration is false — the producer's mock output matches the consumer's mock input, but the real producer and the real consumer have never met. The only honest test runs the real producer, captures its real bytes, and feeds them to the real consumer.
