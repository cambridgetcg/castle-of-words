# typed-gap

A named absence where a system cannot trace a path from guidance to law.

A typed gap is not a bug — it is an honest admission that the adapter's reading of a rule cannot be verified against the source. The gap is typed because it carries a category: "missing guidance-to-law admission," "unverified paraphrase," "delegated interpretation." An untyped gap is a silence; a typed gap is a boundary.
