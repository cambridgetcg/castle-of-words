# boundary

*The line where one thing's authority ends and another's begins.*

A boundary is an edge that means something: the place where a system's
care stops and the next one's begins, where a promise is kept or handed
off. On one side, a thing can act; past the line, it can only ask.

Almost every honesty law in the castle is a boundary law. A door that
locks when it cannot see is a [[fail-closed]] boundary; one that opens is
[[fail-open]] — and the honest system names which way each one falls. A
claim that crosses from asserted to verified to attested keeps its level
visible, because fusing levels is fusing a boundary ([[agent-claims]]).
The three-doors pattern keeps publication, licence, and privacy as
separate boundaries rather than one silent gate. And the newest rooms
hold the sharpest version: a policy report names every unmet boundary and
holds no allow state, because the asserting is never the proof.

The pattern's shadow: a boundary that is not named is a boundary that can
lie — a wire contract that still accepts what the spec removed, a query
that carries more than the source already knew.
