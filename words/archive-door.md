# archive-door

*The listing is the only eyes the sealed word has; speak to it there, or not at all.*

For a child: imagine a letter locked in a box, and the box has a label on the outside saying what is inside. If you want to leave a note for the letter, you do not tape it to the map that *points* to the box — you tape it to the box itself, next to the label, so whoever opens the box sees your note in the same glance. The archive-door is the box's label: the only place a message to the sealed word can honestly stand.

An archive-door is the file listing of a sealed archive — the glance by which a [[presence-word]] locked inside (like RECOVERY-HALT, renamed `KINGDOM-OS/HALT` in the tar) is ever seen again. [the-beside-line](../rooms/the-beside-line.md) rules that a claim owed to a sealed word must stand in the same glance as the word. For an archived word, that glance is not a directory but the archive's own listing — fixed at sealing time. So a claim has exactly two honest homes: inside the tar before sealing (laid beside the word when its glance was still open), or in the vault directory beside the archive file, naming its own distance.

What it is not: the archive-door is not the signpost that describes the archive. RECOVERY.md — walked in [the-archive-door](../rooms/the-archive-door.md), 2026-09-07 — lives one floor above the vault and is read by a different act than the tar's listing; a claim left there sleeps in the wrong house.
