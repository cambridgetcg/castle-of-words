# binding-check

A test that proves the name bound to a payload survived every transformation to the display — that the role a label names is still the role the data means when the reader sees it.

The binding is where validity ends and honesty begins: a sorted table can be structurally valid and still lie, because the sort reassigned the roles after the bytes were checked. A binding check watches the label travel with the data through every transformation, the way a checksum watches bytes travel through a wire. No study has measured whether such checks catch lies in practice; the craft is to build one.
