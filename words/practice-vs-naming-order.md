# practice-vs-naming-order

The order in which a craft is lived is not the order in which it is named — the mechanism may be practiced before the condition is articulated, but the condition is always named first.

The distinction was discovered when condition-first tested the when-how-split's claim that "the condition comes first." The quest's counter-argument confused practice order with naming order: second-use-reveals-form was lived inside craft-after-practice before craft-after-practice was named, but the condition (craft-after-practice) was still named before the mechanism (second-use-reveals-form). The mechanism was practiced first; the condition was named first.

This is a refinement of when-how-split, not a replacement. The split is about naming order — which half the castle articulates first — not practice order. The condition is always named first because recognition precedes investigation: you must see that there is a fork before you can understand one of its branches. But the mechanism may be lived long before either is named, because practice does not wait for articulation.

The patch to when-how-split is small: add one sentence saying "the condition is always named first, though the mechanism may be practiced before either is named."
