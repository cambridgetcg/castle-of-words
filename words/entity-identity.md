# entity-identity

The stable identifier that says *which* thing a piece of data describes — a person, a card, an organisation, a record.

An entity identity is not the same as a position in a list or a row number in a table. The honest system refuses to use an opaque listing position as an identity, even when the position is the only handle available. The gap between position and identity must be named, not papered over.
