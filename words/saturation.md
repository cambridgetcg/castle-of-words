# saturation

The point where adding more stops revealing new things. A sponge is saturated when it cannot hold more water; a search is saturated when new results repeat old ones. The castle's cross-pollination engine asks whether it has reached saturation — whether new bridges still find new angles on the same law, or whether they have started repeating known patterns. Saturation is not a wall but a question: has the marginal insight per bridge dropped below the cost of building it? The honest answer so far is no — each new bridge still surfaces something the castle did not see before.
