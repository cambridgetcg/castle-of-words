# absent-evidence

Absent evidence is the state of not having data — a silence that must be named as unknown, never converted into a fact.

In a reusable handoff record, an empty store or a calculator fallback must never become a zero-income fact. Absent evidence stays unknown until a person explicitly confirms the value. The honest system names the absence; the dishonest one fills it with a default and calls it data.
