# rights-provenance

The three separate hands behind every work: the maker (who created it), the rights holder or other lawful basis (who can grant permission), and the authority (who decides what a project does with it).

A commit proves the maker pushed bytes. An account proves someone logged in. A model output proves a prompt was answered. A domain login proves DNS control. An ability to merge proves repository access. None of these proves any of the other hands. The honest system keeps the three hands separate and names which hand each piece of evidence actually touches.
