# narrow-brake

A mechanism that can stop a process but not steer it — the brake says "no further" without saying "go this way instead."

In a [[protocol-lineage]], each generation carries its own narrow brake: a way to halt that generation's extension without controlling what the next generation does. The brake is narrow because it governs only its own generation — it cannot reach backward to rewrite the past or forward to command the future. A narrow brake is what keeps a [[bridge]] from becoming a [[bridge-authority|home]].
