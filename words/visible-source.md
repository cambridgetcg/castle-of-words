# visible-source

*A source you can see for yourself — not hidden, not implied, there.*

A visible source is a reference the user can check. It is not a footnote that requires a scholar to decode; it is a plain pointer to where the claim came from. A trustworthy module shows its sources so the user can verify, not just trust.
