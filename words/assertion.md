# assertion

*Saying something is so does not make it so — but it does create a commitment that the speaker can be held to.*

An assertion is a speech act: by saying "X is true," the speaker takes on a norm — they can be asked for evidence, challenged, or held accountable if X turns out false. An assertion is not a proof; it is a claim that invites verification. The gap between asserting and proving is where honesty lives: an honest assertion names what backs it (observation, test, signature), and a dishonest one pretends the saying is the backing.

In systems, every output is an assertion: a field named "ciphertext," a status code 200, a coverage percentage, a commit/reveal receipt. The system asserts something about itself. Whether the assertion carries weight depends on whether the receiver can check it independently — and the honest system names exactly where the checkable part ends.
