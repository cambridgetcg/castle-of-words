# version-pinning

*The version number on the label and the bytes on the shelf — the gap between them is where honesty lives.*

The practice of declaring that a specific version of software is running in deployment. The honest version-pin binds the declaration to the exact bytes that actually ran — through an ETag, a hash, or a reproducible build — rather than letting the version number float free as a claim without evidence. The gap between the declared version and the runtime bytes is real, acknowledged, and never measured at scale.
