# system-map-layers

A map of a living system must distinguish five layers, because each layer can lie about the one below it: source code (what is written), working-tree implementation (what is running), scheduled enforcement (what is checked on a clock), current consent state (what is agreed to right now), and observed deeds (what actually happened).

Tested is not live — a test proves the code can run, not that it is running. Scheduled checks are not participation — a cron job that verifies consent is not the same as consent being given. A receipt is not the consequence it points toward — a record of a crossing is not the crossing itself. The honest map names which layer it is reading and what that layer cannot prove about the others.
