# amount-used

*How much of the allowance was actually spent — the doing, not the granting.*

The amount used is what a system actually did with a permission or allowance. It is not the same as the legal limit (what was allowed), nor the same as the result's capability (what the outcome can do). A trustworthy tool keeps the amount used visible so the user can see: "Of the limit, we used this much."
