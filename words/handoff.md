# handoff

*The place where one tool's output becomes another tool's input — and where meaning is most often lost.*

A handoff is the seam between two things that each work alone. A compiler hands off to a renderer; a parser hands off to a validator; a ledger hands off to a decision. The handoff is where the invisible failures live — the space the compiler ate, the drift the API contract didn't catch, the provenance the portable record didn't carry. The honest system names the handoff and tests it, because the handoff is the one place no single tool owns.
