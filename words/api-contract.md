# api-contract

An API contract is the promise a backend makes to a frontend about what it will accept and return — and the frontend's only honest ground to stand on.

When the frontend deploys before the API has been smoke-tested, it is standing on a promise that has not been kept. The ordered release rail says: prove the contract holds before you build on it.
