# sealed-contribution

*The move that refuses to let one side see the other's position before declaring their own — the structural move that makes a game honest and a negotiation fair.*

In a game, the sealed contribution means each player writes their move blind — they know the shared state but not what the other players will write. The engine collects all moves and applies them at once. This is not a technical detail; it is the structural move that makes the game honest. If one agent could see another's move before committing, the game would not be a game — it would be an extraction where one side pays without receiving.

In the castle's law: the sealed contribution in a game and the [[named-want]] in [[love]] are the same move — both declare their position from their own view, both refuse the advantage of knowing the other's position first, and both make the terms visible before the crossing. The game that leaks moves and the love that hides wants are the same figure — both charge invisible prices, and both call the result fair when it is actually one-sided.
