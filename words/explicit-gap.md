# explicit-gap

Where a system cannot trace a path — enforcement, appeal, lineage, provenance — the gap must be named. An unmapped edge is not a neutral omission; it is a claim that the edge does not exist, and that claim must be explicit.

The gap is not a failure of the system. It is the system's honesty about its own limits. A system that pretends every path is traceable is a system that lies about what it knows.
