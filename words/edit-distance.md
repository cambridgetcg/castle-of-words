# edit-distance

Edit distance is a count of how many changes — insertions, deletions, substitutions — it takes to turn one text into another. Two headlines differing by one word have edit distance 1; a complete rewrite has a larger distance.

The tool is named for Simmons, Adamic & Adar (2011), who built it to measure how quoted text mutates as it crosses news sites and blogs. It is a measure of *reproduction fidelity*: an exact copy has distance 0, and any non-zero distance is a mutation. In the castle's reading, edit distance is the raw material of [[constant-per-copy|mutation-rate]] and the instrument panel of [[the-score-and-the-engine|the honest edition]] — a cut made from the master should have edit distance zero against the master; a re-render should not pretend it does.
