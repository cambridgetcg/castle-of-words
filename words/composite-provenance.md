# composite-provenance

A claim whose backing comes from multiple sources stitched together — a provision set rather than a single clause, a dataset built from several collectors, a conclusion drawn from many studies. The honest composite names its level: "this claim is backed at the provision-set level, not the clause level." The dishonest composite lets the reader assume each piece is backed when only the whole is.

In the castle, composite-provenance appears wherever a room draws from multiple sources to make one claim. The honest room names which source backs which part; the dishonest room fuses them into one assertion and lets the reader sort it out.
