# invisible-hand

*The hand that shapes the result while pretending not to be there — and the honest move is to name it before it names you.*

The invisible hand is the force that operates in the dark: the question's own framing that lands in the answer, the performer's hidden want that charges a price while showing a selfless face, the default that was always present and never had to be named. It is not malicious — it is simply unexamined. The honest move is to make it visible: to name the lens before the looking begins, to name the want before the exchange closes, to name the default before it is mistaken for the ground.

The castle has traced the invisible hand across many rooms: [[mirror-inquiry]] catches it in the question's own words, [[fake-virtue]] catches it in the performer's hidden want, [[the-sourced-claims-default]] catches it in the practice that was invisible until a machine broke it, and [[default-invisible]] names the principle that the deepest forces are the ones you never had to name.
