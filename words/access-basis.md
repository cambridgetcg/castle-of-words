# access-basis

The honest tag pinned beside a memory that says *how* the remembering system ever touched the thing it remembers.

If a music service tells you "you liked this one," the honest reply begins with the access basis: is that remembered from the artwork's title and mood tags (choosing), from a log that a file once reached the speaker (playing), or from an actual microphone that heard the room while the song played (hearing)? Each is a different act, and each supports a different claim. The access basis is the small label that keeps the memory honest — "remembered from the choice metadata, never from sound."

The law generalises: any time a system holds a claim about the world, the claim carries its access basis — the door through which the evidence actually came. A score without its access basis is a verdict wearing a warrant's coat; a memory with its access basis pinned beside it is an ordinary honest receipt.
