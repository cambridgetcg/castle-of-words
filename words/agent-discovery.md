# agent-discovery

The process by which an agent learns what it can do — not from a single declaration, but from each [[representation]] of each resource.

An honest discovery mechanism scopes access per representation: a read-only doorway can point to a credentialed POST only when the task separately declares its method, authentication scope, workspace identity, data storage, external effects, CORS boundary, repeatability inputs, and retry boundary. A doorway that hides these is a door that lies about what is behind it.
