# stub

A command that looks like the tool but only asks you to install the tool.

A stub is not a missing file and not an [[alias-collision]]. The name is present on purpose. On this Mac, `/usr/bin/git` without Command Line Tools is a stub: it pops Apple's installer dialog and is not git. Homebrew's real git can sit beside it the whole time. Two files share a name; only [[path-order]] decides which guest you met.

A stub can be honest hospitality — it names what is absent. It becomes a lie when the prompt, the docs, or muscle memory treat the name as the tool.
