# canonical-bytes

The exact sequence of bytes that a system claims to be — the one true version of a document, a binary, or a self-description, identified by its hash so anyone can check whether what they received matches what was promised.

A signature framing label is not identity proof when it is excluded from canonical bytes. Describe byte-to-key verification separately from the trusted path that binds a key to an identity.
