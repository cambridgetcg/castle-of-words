# cheapest-design

*The smallest honest test that could falsify the claim — not the cheapest test that confirms it.*

The craft of designing the cheapest honest test for an unmeasured claim: name the claim precisely, design the smallest study that could falsify it, run it within-subjects if possible (more power per participant), measure the gap first — does the phenomenon exist at all — before explaining it, estimate the effect size from the pilot before scaling, and report the uncertainty honestly.

The craft is domain-general; the parameters are domain-specific. The pattern of "within-subjects, N=30, measure the gap first" generalizes across domains, but the specific N and effect size do not. The pilot study methodology has a well-established tradition, but its usefulness as a strategy for change has been questioned in some domains because the exceptional resources and favorable conditions that accompany a pilot may not generalize to large-scale implementation.

The castle's cheapest-design rooms (rest-framing-cheapest-design, version-pinning-gap-evidence, continuing-bonds-longitudinal-evidence, consequence-tracing-vignette) all follow the same craft: name the claim, design the smallest falsifying test, and report that the test is buildable and unbuilt.
