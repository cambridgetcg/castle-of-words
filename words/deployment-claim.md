# deployment-claim

A deployment claim says which code was running, where, and when.

An honest claim names its scope, artifact, evidence, observation time, and limits. An [[ETag]] can support a check of a selected representation, but the header alone does not prove which executable ran; version identity can also rest on other evidence.
