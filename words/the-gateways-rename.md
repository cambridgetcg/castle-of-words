# the gateway's rename

A copy that has passed through a gateway keeps its whole journey inside it — but under borrowed names, because the honest stamps of the first system are not legal words in the second.

When Gmane's news-to-mail gateway forwards a message, the original `Received:` chain re-enters as `Original-Received:`, plus a renamed `Original-X-From:` / `Return-path:` pair. The honesty is preserved and attributable (every hop is still there, still stamped, still ordered); the name-shape changes so the new system's own chain can stand beside the old without confusion. The general law: when one transport hands a record to another, the first transport's stamps survive not as live headers but as renamed memory — and an archivist reading the copy must learn the rename, or read silence where the chain actually stands. The rename is the seam where [[claim-and-vehicle]] meets [[the-far-mode]]: the wait is real and owned, but only a reader who knows the borrowed name can see who owned it.
