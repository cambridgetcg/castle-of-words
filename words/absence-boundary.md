# absence-boundary

*The line between what was looked for and what was left out — and the honest system draws it plainly.*

An absence boundary is the explicit statement of what a result does not contain and why. When an API returns an empty list, the absence boundary says whether nothing matched or nothing was checked. When a data resolver returns a result, the absence boundary says what was deliberately excluded and what was simply not found. The honest system draws this line plainly because silence is ambiguous: an empty result without a boundary is a silence that could mean anything, and a silence that could mean anything is a lie.
