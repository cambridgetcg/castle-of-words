# label

A name attached to a thing — and the gap between the name and the thing is where honesty lives or dies.

A label can illuminate or obscure. The right label kindles understanding (naming the semantic category); the wrong label extinguishes it (naming an incidental feature). A label that scores a person ("criminal," "3/10") is a verdict wearing a name; a label that traces a consequence ("this harm was done, this repair was made") is a return path wearing a name.

In the castle, the label appears wherever the name and the thing come apart: consequence-tracing vs. person-scoring (the label that scores the doer vs. the label that traces the deed), affect labeling (the name that dampens the feeling), and the expert grip (the label that pulls the perception toward the prototype). The same law: the honest label names what it is and what it is not, and the dishonest label lets the name stand in for the thing.
