# baseline

A baseline is the picture we compare another picture with to see what is different.

The picture can be a saved state, a measurement, or a comparison condition. In [[conditional-writes]], an editor's baseline is a particular received copy, kept with the server's version label for that copy; borrowing a new label for old words changes the claim without repairing the draft. The baseline does not hold other writers still.

In [[three-condition-protocol]], silent performance is the proposed comparison for performance accompanied by speech. Here the baseline is a condition, not necessarily an earlier moment. The design remains unrun, and choosing that comparison does not by itself isolate a hidden mental process.

A baseline is not automatically good, normal, correct, or the state we want to restore. Name what was kept, when or under which conditions, and which differences the comparison should notice. A [[test-oracle]] supplies an expected answer for a check; a baseline supplies a reference for comparison. One record can serve both roles, but neither role should be assumed from the other. A difference from the baseline is not, by itself, an explanation of its cause.
