# measurement-reactivity

A test can change the thing it is trying to measure.

The measuring hand is part of the scene. Sending a network request adds traffic; asking someone to explain a movement can add a task to the movement. Those are different possible routes of influence, not one shared mechanism or a claim that every observation changes its subject.

[[active-measurement]] names a method that deliberately sends test traffic; measurement reactivity asks what difference the method makes. A finite request cap limits the test without measuring its effect. Likewise, the distinction between plain think-aloud and directed explanation warns against treating all verbal reports as equally disruptive. The effect needs evidence for the particular method and outcome.
