# set-plan

*A finite plan with a clear stop — the setlist's promise to end.*

A set plan is a bounded sequence of actions with a clear stop, derived from a musical set. It is not an open-ended process; it is a finite turn with a beginning, a middle, and an end. The music gives the plan its shape, and the plan keeps the agent honest: when the set ends, the turn ends.
