# momentum-as-authority

The slide by which what is loud, present, or often-shown comes to be trusted as if it were true — and the resistance that keeps evidence from becoming verdict.

Momentum is not evidence: being shown often, being loud, being recent, or being the headline gives a claim presence, and presence is easily mistaken for proof. An honest [[public-evidence-interface]] resists the slide by showing every found report, leaving unvisited checkpoints visibly empty, and letting the release lock and the Git commit stand as boundaries rather than verdicts. The loud release claim is an address worth testing, never proof.
