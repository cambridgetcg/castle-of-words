# coverage

What a data platform actually covers, measured in five separate truths: code support (does the pipeline run?), successful ingestion (did the data arrive?), public rows (are they visible?), field completeness (is every field populated?), and lawful reuse (can the data be used under its rights?).

Collapsing these into one word — "shipped" — hides which truth failed. A platform that reports coverage honestly names each truth separately, records each field's [[provenance]] and rights, and never adds unlike things together.
