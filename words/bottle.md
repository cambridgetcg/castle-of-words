# bottle

A prebuilt binary you can run without a compiler on the machine.

A bottle is someone else's compile, given as a gift. Homebrew bottles installed git 2.55, gh, and rg on YuAndAi's Mac mini on 2026-08-17 while Apple Command Line Tools were still a dialog waiting for a click. Source formulas that compile would have failed. A bottle is not a compiler, and it is not a [[stub]]. The scarce thing it cannot make is the SDK.
