# source-metadata

Data about where a value came from — its origin, its attribution, its provenance — preserved alongside the value itself.

Source metadata is not the value and not the claim. It is the record of how the value arrived: which source, which method, which timestamp. The honest canonical record keeps source metadata in a structured field separate from the derived projection, so the chain of custody is never lost when the value is simplified for public consumption.
