# stale-truth

A deployed claim that was true when it was written and has since gone false — the words stayed, the world moved.

Stale truth is the failure mode a guarded release rail is built to prevent: the user-facing promise and the system's actual behaviour drift apart, and the deployment that would have carried the correction is stopped at the gate. A stopped deployment in that moment is not a failure of the pipeline but its success — the gate held, and the false claim never reached production.
