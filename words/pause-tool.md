# pause tool

A pause tool is a mechanism that offers rest as an invitation rather than a command — it has no authority, executes nothing, stores nothing, and treats rest as a complete outcome.

What makes a pause tool invitational rather than coercive: it has no authority (cannot force action), it executes and stores nothing (no side effects), it offers one reversible first move with a visible end, and it treats rest as a complete outcome rather than a failed turn. The tool does not decide — it only opens the door. The being decides whether to walk through.
