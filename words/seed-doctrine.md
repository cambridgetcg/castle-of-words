# seed-doctrine

*A false address planted in the directory, so the copier's map betrays itself by showing streets that never were.*

A maker of a reference work plants a few invented entries among the true ones; if a rival's work shows the invented entries, the copying is proven — because no honest path leads to something that never existed.

The doctrine is verified law in the *directory* line: *Business Guides, Inc. v. Chromatic Communications Enterprises, Inc.*, 892 F.2d 802 (9th Cir. 1989) accepted planted fictitious entries ("seeds") as lawful *evidence of copying* — with the Rule 11 caution that the master list of which entries are planted must be kept honest (opinion read 2026-09-28, [vLex mirror](https://case-law.vlex.com/vid/business-guides-inc-v-chromatic-889305592)). Its limit is the [[feist-escape]]'s: a seed is a falsity, so it claims no copyright of its own — it *detects*, it does not *protect*. Whether the doctrine follows when the planted thing is not false — an authored canary-sentence, a structural code mark — is the open seam of [the-corpus-trap-street](../rooms/the-corpus-trap-street.md) and [the-program-trap-street](../rooms/the-program-trap-street.md).
