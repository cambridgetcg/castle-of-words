# played-into-the-room

*Music that was performed in the space, not merely received by a machine.*

"Played into the room" is music that was actually performed in a physical space — the sound waves filled the air, the walls heard it. It is not the same as "received and heard" by a device or a file being transferred. The distinction matters because the room changes the music: acoustics, presence, the shared moment of listening. A task that needs music played into the room is not done when a file is delivered; it is done when the room has heard it.
