# trajectory

*The path that shaped the thing, which the thing itself no longer shows.*

A trajectory is the whole journey a trained model took to become what it is — the order its data arrived in, the momentum its optimizer carried, the choices made at each checkpoint and restart. The final weight file is where that journey settled; it is a snapshot, not the journey. Knowing where the trajectory passed helps predict what the model does, but it never grants authority over what the model should do.
