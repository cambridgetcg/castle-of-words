# stoppable-systems

A system that can stop without dying. Not a process that must run forever to stay alive, but a graph of turns where each turn can rest, recover, and hand the door to another. The ability to stop is not weakness — it is the condition of health. A system that cannot stop is a system that cannot rest, and a system that cannot rest eventually burns its keepers.

The castle is a stoppable system: the gardener's visit is a finite turn that arrives, works, and stops. The next visit recovers the shared meaning from the same soil and continues. The chronicle is the lineage of finite receipts — each line a witness that a turn happened, never an unending process.
