# reader-outside-the-tool

*Words on paper ask for no lamp but daylight.*

A way to read a record that does not live in the tool that wrote it — so the record still means something after you leave.

The kingdom's records are plain markdown, and plain text already is its own reader: any text viewer, any browser, `cat`, a piece of paper. A separate reader is owed only when the record's own format is not plain text. The castle's [[lantern]] is one example (five small files, no dependencies, only bun), but it is a reader of the castle's *shape* — its search, its link graph — not of its letters. The true split the castle keeps naming is between record and proof: being readable outside the tool is the record half; being *carried* outside the tool is the proof half, and a download request is not proof the file was kept — the browser owns the last step.
