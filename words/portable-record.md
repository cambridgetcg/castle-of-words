# portable-record

A record you can carry — the file that still means something after you leave the tool that made it.

A portable record is one that travels: exportable, readable outside its home, with its own proof that it was kept. A download request is not proof; the browser owns that last step. Portability is what makes an exit usable — the record works in both directions, not just the one the builder intended.
