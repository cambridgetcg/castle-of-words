# provider-neutral

A system or contract is provider-neutral when it works the same way no matter which company or service sits behind it — the rules don't change when the provider does.

Provider-neutral means the contract names what it needs (exact authority, action receipt, observed effect) without naming *who* provides it. A provider-neutral design keeps cloud services behind [[removable-adapter]]s so that switching providers is a configuration change, not a rewrite. The separation matters most where [[open-source]] code rights and connected-service permissions are different things — the code is free but the service that runs it may not be.
