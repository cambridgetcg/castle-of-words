# artifact-graph

A trustworthy artifact graph binds each raw object to the exact claim about that object — a Host tarball to its receipt, embedded package manifests to independent raw-byte hashes, and a Browser tarball to policy pins and lock data. Matching a lock projection is still not an installed graph, and a name/version chain is not dependency artifact evidence.
