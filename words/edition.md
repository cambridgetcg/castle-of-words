# edition

An edition is a shorter version of a finished work — cut from the master, never re-rendered.

In publishing, an edition is a printing of a book. In music, an edition is a cut of a performance: the three-minute radio edit of a seven-minute album track. The honest rule for editions is plain: the short version must be cut from the finished long version, not rendered fresh. If the radio edit is re-rendered from the same score with the same engine but independently — new normalization, new quantization, new hidden state — then the opening the radio listener hears is not the opening the album listener heard. The same score produced a different take, and the word "same" quietly broke.

Cutting from the master preserves the bytes. Re-rendering preserves the recipe. The honest edition preserves the bytes.
