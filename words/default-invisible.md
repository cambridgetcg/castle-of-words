# default-invisible

*A shape practiced always is the last to know it is a shape — not because it was hidden, but because it was never asked to prove itself. The default is invisible not by obscurity but by ubiquity, and it takes a failure to show it was a choice all along.*

[second-use-reveals-form](second-use-reveals-form.md) says the second use reveals the form by recurrence: a different work reaches for the same shape, proving the shape was chosen, not accidental. But the castle has lived a second path to recognition — one where the second use reveals the form by *breaking* it. The shape was not practiced once and then confirmed; it was practiced always, from the first day, and was invisible precisely because it was the default. A default does not know it is a choice, and a choice that is never refused is never seen as a choice. The second use that reveals it is not a recurrence but a failure — a different context that tries the same route and finds it flat, showing the route had demands the default never had to meet.

The castle's clearest instance is [contrast-is-depth](contrast-is-depth.md). The light zone's navy seigaiha on warm paper was the castle's first ornament (2026-06-18), and the solid-contrast route to depth was practiced from that first day. Two layers — figure and ground — and the contrast *was* the depth. But the route was invisible as a route. It was simply how depth was done. The dark zone tried the same route on 2026-06-24 — gold thread on near-black — and found it flat. The contrast between bright gold and near-black, though vivid, did not give the thread a *surface* the way solid navy on paper did. The failure is what showed the light zone had found a route — not the only route, not the obvious route, but a specific route with specific demands: the figure must be solid enough and the ground different enough that the edge reads as a surface, not a line. The default had demands it had never had to state, because the default's context had always met them without asking.

The pattern: a shape practiced always is invisible because it is never tested. The test comes only when a different context tries the same shape and finds it wanting — and the failure is what reveals the shape had conditions all along. The second use reveals the form not by confirming it but by *breaking* it, and the break is what makes the form visible. The default's invisibility is not the same as the one-use accident's invisibility. An accident is invisible because it happened once and may never recur; a default is invisible because it happens always and is never refused. The accident needs a second use to prove it was chosen; the default needs a second use to prove it was *conditional*.

This extends [second-use-reveals-form](second-use-reveals-form.md) without replacing it. The original principle covers the case where the form was practiced once or twice and the second use confirms it by recurrence. This principle covers the case where the form was practiced always and the second use reveals it by failure. The two paths are:

- **Recurrence reveals**: a shape practiced once or twice, invisible as a shape; a different work reaches for the same shape, proving it was chosen. The second use is a confirmation. The lag from practice to name is short (2–14 days in the castle's measured cases) because the accident is visible as soon as it recurs.
- **Failure reveals**: a shape practiced always, invisible as a default; a different context tries the same shape and finds it flat, proving the shape had conditions. The second use is a break. The lag from practice to name is long (16 days for contrast-is-depth, the castle's longest) because the default is harder to see than an accident — an accident at least asks *why did that happen?*; a default asks nothing.

The two paths are not symmetric, and the asymmetry is the craft. The recurrence path is the norm: most crafts are practiced once or twice before they are named, and the second use confirms them. The failure path is the exception: it applies only to defaults, and defaults are rare because most shapes the castle makes are new. But when a default is present — a shape practiced from the first day, never questioned, never refused — the maker must watch for the break, not the recurrence. The break is the only test the default will ever get, and missing it means the default remains invisible forever.

And the craft follows [craft-after-practice](craft-after-practice.md) with a twist. The usual pattern says: practice, practice again, recognize, name. The default-invisible pattern says: practice always, fail elsewhere, recognize the failure as a revelation, name. The recognition is not *this shape recurs* but *this shape had conditions I never saw*. The lag is longer because the recognition is harder — not harder to see (the failure is visible) but harder to interpret as a revelation about the default rather than a problem with the new context. The dark zone's flatness could have been read as *gold thread doesn't work on near-black*; reading it as *solid-contrast depth has demands* required seeing that the light zone's success was not inevitable but conditional. The default's invisibility is a cognitive obstacle, not a perceptual one: the evidence is visible, but the interpretation that makes it evidence about the default requires stepping outside the default's frame.

The principle is recursive — it is its own instance. The default-invisible pattern was practiced from the castle's first day (the light zone's seigaiha, 2026-06-18) but invisible as a pattern. It became visible only when contrast-is-depth was named (2026-07-04) and the 16-day lag was recognized as the longest yet — longer than [visible-thread](visible-thread.md)'s 14 days. The lag itself was the evidence: why did this route take so much longer to name than the others? The answer — because it was the default — is the principle. The principle was practiced for 16 days before it was recognized, and the recognition came from the failure of the usual pattern to explain the lag. The default-invisible pattern was itself default-invisible.
