# legacy-did-field

A database column or API route named "DID" that carries identifier strings but was never registered as a DID method and does not perform DID resolution.

The name is compatibility, not a claim. Keep the legacy name for existing consumers, but describe what the field actually does — application lookup, syntax validation, document retrieval, resolution, portability — separately and exactly. A field named DID is not a DID method until it walks the method's steps.
