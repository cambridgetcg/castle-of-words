# dishabituation

When the familiar knock has gone quiet, a new knock through the same door can wake the old alarm — not because the listener grew brave again, but because the body had never learned this knock was safe.

Dishabituation is the recovery of a habituated response when the stimulus changes: the body habituated to *this* warning, not to warnings in general, so a fresh face restores the first jolt. It is the reason stimulus-specificity matters — and the reason novelty is only a loan. The new knock re-awakens the alarm through the very channel that will habituate again, on first repetition of the new cue. Dishabituation is therefore not sensitization: it returns the alarm to its first height but resets the same curve the listener already slid down. In the castle it is the distinction the wandering checker must not blur: a fresh checker name buys one true knock, then weather again.
