inbox (<https://yhetil.org/orgmode/>).

machine, trimmed down the config, and created a fresh index.  Here's the
entire test config:
[publicinbox "orgmode"]
address = emacs-orgmode@gnu.org
inboxdir = /tmp/event-step/orgmode
url = https://yhetil.org/orgmode/
Next I tried some of the requests.  For nearly all of the timestamps,
there is more than one request.  I haven't gone through each one, but I
have been able to trigger the issue with the cloned inbox.
$ public-inbox-httpd
Changing use VERSION while another use VERSION is in scope is deprecated, and will become fatal in Perl 5.44 at [...]/lib/PublicInbox/Git.pm line 675.

Each case I've triggered so far is for a _message ID that's not found_.
Here are three examples:
/orgmode/F1BFD612-B50C-4247-8261-1058352CF0E4@gmail.com
