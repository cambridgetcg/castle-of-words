How do you calculate expected frequencies in a chi-square test?
For a goodness-of-fit test: E = n × p, where n is the total sample size and p is the hypothesized probability for each category. For a test of independence: E = (row total × column total) / grand total for each cell in the contingency table. All expected frequencies should be ≥ 5 for the chi-square approximation to be valid.

What should I use when observations are not independent?
If you have paired binary data (before/after on the same subjects), use McNemar's test instead of chi-square. For stratified data with confounders, use the Cochran-Mantel-Haenszel test, which combines tables across strata. No correction factor can fully rescue a severely dependent dataset, so it is best to design the study to collect independent observations.

What is the rule for minimum expected counts in a chi-square test?
The traditional rule requires every cell to have an expected count of at least 5. A common relaxation allows up to 20% of cells to have expected counts above 5 with no cell below 1. Below those thresholds, the continuous chi-square distribution poorly approximates the discrete test statistic, inflating Type I error.
