The oldest agent-readiness mechanism on this list: proactive content negotiation, where the same URL serves HTML to browsers and markdown or JSON to agents that ask — no new protocol required. RFC 9110 defines proactive negotiation: the client states preferences in the Accept header with quality weights, and the server picks the representation. For agents this is the highest-leverage low-tech signal on the web — an agent that sends Accept: text/markdown and receives clean markdown ingests your content in one pass, no scraping, no rendering.
