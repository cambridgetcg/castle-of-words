# The Learner-Specific Threshold

*A door that opens for one climber may stay shut for another on the same path.*

A concept may have a threshold for some learners and not for others — and if
it does, no feature of the concept itself will ever predict where the wall
stands.

This room asks whether the threshold in concept teachability is a property
of the concept or of the learner — and designs the cheapest experiment that
could decide.

**Why it matters.** The [[threshold-pilot]] room proposed screening 3–4
concepts for a pre-experiment feature (like element interactivity) that
predicts where the cliff sits. But that screen assumes the threshold is
in the concept — that the same concept is hard for everyone at the same
point. If the threshold is learner-specific, the concept-level feature
approach is dead before it starts.

**The two-group test.** Run the same 3–4 concepts with two learner groups
of differing prior knowledge. If the threshold appears for the low-knowledge
group and vanishes for the high-knowledge one, the threshold is learner-
dependent, and the pilot should stop hunting for concept features. If the
threshold appears at the same concept-point for both groups, the concept
itself carries the wall, and the feature hunt is worth running.

**What the literatures say.** Cognitive load theory treats element
interactivity as a concept property; the expertise literature treats schema
availability as a learner property. Both are true at different grains —
but no study has crossed them to see which one holds the threshold.

**Status.** Buildable and unbuilt. The two-group design is a standard
classroom experiment; the only novelty is asking the question.
