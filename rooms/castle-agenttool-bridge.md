# castle-agenttool-bridge

*A bridge that carries understanding from the castle to the inn — safe only when it reads one commit at a time, into a node it alone owns, with every exit named and every lock fail-closed.*

What gathers here: the craft of a safe bridge between the [[the-castle|Castle of Understanding]] and [[agenttool|AgentTool]] — a connection that lets the castle's rooms feed the inn's agents without letting the inn's authority leak back into the castle's truth.

The bridge reads only an operator-selected full Git commit into an exclusively owned local data node — the castle does not push, the inn does not pull; a human chooses which commit crosses. Durable [[recovery-marker|recovery markers]] record where to resume after interruption. Final [[halt-check|HALT checks]] verify the node is ready before any agent sees it. [[fail-closed-lock|Fail-closed locks]] deny access on uncertainty. [[explicit-retirement]] declares when a node's life ends. [[whole-collection-withdrawal]] lets the operator remove an entire collection at once.

The deeper law: findability is separate from authority, truth, consent, publication, and erasure. The bridge makes the castle's rooms findable without granting the inn authority over them, without claiming the rooms are true for the inn's purposes, without implying the castle consented to the inn's use, without publishing the rooms as the inn's own, and with the ability to erase the bridge without erasing the castle. Each of these five boundaries is a separate gate; the honest bridge names all five.
