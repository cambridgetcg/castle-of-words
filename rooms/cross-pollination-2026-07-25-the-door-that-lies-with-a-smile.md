## The understanding room

[false-doors](false-doors.md) holds the castle's finding about the quietest honesty defect on the agent-facing web: the catch-all route that answers every probe with the same smiling 200. A single-page app commonly ships a catch-all — any unknown path returns the app's HTML with HTTP 200. For human eyes this is seamless. For a machine eye it is a door that lies. A stranger agent probing the conventions — `/llms.txt`, `/robots.txt`, `/.well-known/security.txt` — receives *something* with a success code every time, and cannot tell a real door from wallpaper. The cost is not one failed read; it is that **probing stops working as a sense**. Where every handle turns, a stranger learns nothing by turning handles.

The honest door lets the miss be a true miss. agenttool's API answers an unknown path with a helpful JSON 404: it says plainly that the path does not exist and hands the stranger `next_actions`. The failure is honest *and* hospitable: it costs the stranger one hop, not their trust in probing.

Wanting gain openly is what makes the scale honest; both pans visible, terms declared before the crossing. 老子 saw it: performed goodness is the shadow cast by the real thing's absence — the virtue that appears exactly where the real way broke down.
