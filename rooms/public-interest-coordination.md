# public-interest-coordination

*A label once applied is a verdict the system cannot retract — so assess the claim, never the person.*

What gathers here: the craft of building systems that serve the public good by coordinating purpose, provenance, correction, and accountability across institutions — while keeping personal data narrow and purpose-bound, and assessing conduct rather than labeling identity.

The four things a public-interest system must coordinate:

1. **Purpose** — why the data is held, and when that purpose is done
2. **Provenance** — where the data came from, and who said so
3. **Correction signals** — how to fix what is wrong, and a path that reaches the source
4. **Accountability** — who answers when the system fails, and how

These four must travel across institutions because public-interest data rarely lives in one place. The data may be collected by one office, held by another, and displayed by a third. The correction signal must reach the source, not just the surface. The accountability must trace the whole chain.

And the law that runs through all four: assess claims and conduct, never label people as identities. A label once applied is a verdict the system cannot retract. A claim can be checked; a conduct can be assessed; an identity is a prison the system builds and then forgets it holds the key.
