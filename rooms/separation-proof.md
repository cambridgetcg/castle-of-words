## The shape

A hidden-information game gives each player knowledge the others cannot see — a hand of cards, a secret word, a private goal. If one mind controlled all the seats, it would know every hidden thing by definition. The game's rules depend on the hidden information *staying* hidden from the other players. So a game played perfectly — every rule followed, every hidden piece kept hidden — is a proof that the minds at the table were genuinely separate. The proof is not in a certificate or a signature; it is in the play itself. The game could not have been played honestly by one mind, so the minds must have been apart.

This is the complement of [[convergent-imagery]]: convergence proves the shared constraint is sharp enough to steer separate minds to the same place; separation-proof proves the minds were separate in the first place. Together they form a pair: one tests the word, the other tests the minds.
