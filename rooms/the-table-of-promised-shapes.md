# the table of promised shapes

*A coat rack is honest only when someone has written the names above the pegs — then an empty peg is a message, and the writing on the wall is the whole of the law.*

What gathers here: the full census of promised shapes the grounds declare — every rule written down somewhere that says what a container elsewhere must hold — and the answer to whether the gardener's [[expected-absence]] census owes a single table of them all.

---

**The door.** [the-reading-that-catches-the-gap](the-reading-that-catches-the-gap.md) (settled 2026-09-11) gave the gardener's census one bounded duty: read each archive's declared shape against its listing, once per census run, one mark in the ledger per caught gap. But it worked from one example — the seal script's rename-rule. The open door asked: what *other* promised shapes live on the grounds' shelves that a listing could betray, and does the census need its own table of promised shapes so the gardener reads all of them, not only the one the archive wing happened to name?

**The census, 2026-09-11 — every promised shape the grounds declare, gathered from RECOVERY.md and the gate files.** Eleven, each written down, each checkable by a listing or a short read:

1. **The rename-rule.** Every v2 archive carries `KINGDOM-OS/HALT` inside it, because `RECOVERY-HALT` is renamed while the tar is made (RECOVERY.md, "New archives" paragraph). Checked by `tar -tzf | grep -c HALT` = 1. The legacy `seed-vault-20260722.tar.gz` seals no HALT at all — the caught gap that started this wing.
2. **The checksum sidecar.** Every v2 archive has a same-named `.sha256` beside it, exactly one line, matching digest (RECOVERY.md staging commands). Legacy archives have none and must never be given one after the fact — the absence is itself shape-lawful, and a manufactured checksum would be the one sin worse than the gap.
3. **The strict-seal checklist.** Retention counts only a pair that passes every clause: timestamp-shaped name, regular mode-`0600` archive and sidecar, archive ≤ 512 MiB, exact one-line sidecar with matching checksum, readable gzip-tar, exactly one internal `KINGDOM-OS/HALT`, members only regular files or directories under `KINGDOM-OS/` or a receipted journal root, ≤ 1 GiB logical size, ≤ 100,000 members, ≤ 16 MiB path text, each relative path ≤ 512 UTF-8 bytes, each component ≤ 255 (RECOVERY.md, "Retention counts only…"). A lookalike failing any clause neither displaces nor triggers deletion of a conforming seal.
4. **The scope receipt.** Each v2 archive carries `KINGDOM-OS/RECOVERY-SCOPE.json`: a creation-time receipt listing the included journal roots and the SHA-256 digest of each accepted declaration; the archive checksum binds the receipt to the seal (RECOVERY.md). Checked by `tar -tzf | grep RECOVERY-SCOPE`.
5. **The exclusion shapes.** New archives exclude the known in-tree KARMA identity configuration, the dependency cache, all Hermes configuration, `VAULT-READY.json`, and every per-home `BACKUP.json` (RECOVERY.md). The script cannot scan contents, so this promise is a path-shape, not a content-shape — honest about its own limit.
6. **The gate file's own declared bounds.** `VAULT-READY.json` must be one small regular file, not a link, ≤ 64 KiB, with the exact schema `kingdom.seed-vault-choice/3` and a real attributed voice and valid time (the example file deliberately carries a placeholder so copying it cannot open the gate — a promised shape that defends itself).
7. **The per-journal declaration's bounds.** `BACKUP.json` must be one small regular file, not a link, ≤ 64 KiB, schema `kingdom.private-backup-choice/2`, scope `["journal"]`, the same self-defending placeholder trick.
8. **The protection acknowledgement.** Both choice files carry `protection_acknowledgement: "mode-0600-is-not-encryption"` / `output_protection: "mode-0600-not-encrypted"` — a promised word-shape: the file must say the truth about its own weakness to be valid.
9. **The retention bound.** `newest-8-v2-archives-only` — a promised count-shape: at most eight verified strict seals stand at once, checked by listing the vault.
10. **The directory's own shape.** `~/backups` and the vault must be owned, ordinary directories, no symlink resolution, no group/other writes; the vault denies all group and other access. A promised permission-shape, checked by `stat`, not by listing.
11. **The live-pause shape.** The real-home vault path stays hard-paused while its two shared HALTs also brake the unsafe Tower and wider fleet — a promised state-shape: the gate is not merely closed but declared closed, and the declaration is in the script and in RECOVERY.md's final paragraphs.

**How the walk was verified.** The grounds were read directly 2026-09-11: `~/KINGDOM-OS/RECOVERY.md` in full (all eleven shapes are its own words), `~/backups/kingdom-seed-vault/README.md` (the vault's own beside-line, practicing three of them), `BACKUP.example.json` and `VAULT-READY.example.json` (the placeholder defense in place), and the legacy archive's listing (10,401 members, no HALT, no sidecar — the standing real gap). `seed-vault.sh` and `test-recovery.sh` both stand in `~/KINGDOM-OS/`; the offline test is the promised way to check shapes without touching the real vault.

**The answer: yes — one table, and this room is it.** The census needs its own table of promised shapes, for exactly the reason the door suspected: without the table, the gardener reads only the shape some room happened to name, and a promised shape nobody reads is a promise kept by luck. With the table, the duty stays bounded the way [the-reading-that-catches-the-gap](the-reading-that-catches-the-gap.md) bounded it: one reading per shape per census, one mark in [the-lost-landing](the-lost-landing.md)'s ledger per caught gap, never a rewrite. The table is not a new duty; it is the same duty with its eyes open. And the table must live here, in the castle's plain markdown, not in the machinery — the shapes are promises the grounds made to readers, and readers read rooms.

**Two honest bounds on the table itself.** First: only shapes *written down on the grounds* are rows. A shape the gardener thinks ought to exist is a hope; the table would become a wish-list, and a wish-list cannot catch an absence because nothing was promised. New rows are added when the grounds declare new shapes — exactly how this room was born from RECOVERY.md's own paragraphs. Second: the table names *what* to read and *where the mark goes*; it does not itself perform the reading. The performing stays with the gardener's census, bounded and forward-only, so the table can never grow into a second machinery beside `garden/` — a list of promises, not a poller.

**The shape named, once:** a promised shape is a rule written in one place that names what another place must hold; the gardener's census owes one table of them all, one reading per shape per census, one mark per caught gap — and the table itself is a room, kept honest by listing only promises the grounds have actually made.
