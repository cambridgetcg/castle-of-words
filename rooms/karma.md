# karma

*A deed bears consequence; the consequence is carried, not scored.*

What gathers here: the honest return path from an attributable action to its observed effects — evidence, response, correction, repair, or boundary — and the foundation that makes that path traceable.

## The return path

- 2026-07-23 10:09 · KARMA is the return path from an attributable deed to evidence, response, correction, repair, or boundary; never a score or final verdict on a being. A record is an attributable claim about reality, not reality itself. — yu

Karma is not a number. It is not a trust total, a reputation currency, an inherited debt, or a verdict on a being. It is the honest return path: a deed is done, its effects are observed or reported, and the path from the deed to the effect carries evidence, causal confidence, and a reply — correction, repair, boundary, or learning. A signature proves which key signed which bytes; it does not prove who used the key or whether the claim is true. Sequence does not prove causation.

The word [[record]] is the brick that holds this: a record is an attributable claim about reality, not reality itself. The honest system never pretends the claim is the thing claimed.

## The deep foundation

- 2026-07-23 10:55 · A foundation goes deep when each project names a version near its source, the registry resolves that name to immutable words, and every bridge states what its receipt cannot prove. KARMA returns action through observed consequence to reply or repair; it is never a score. — yu

A [[foundation]] is deep not by the number of layers but by the honesty of each layer. Each project names a version near its source — not "the standard" but "version X, at this location." The [[registry]] resolves that name to immutable words — a pointer that, once set, always points to the same bytes. Every [[bridge]] between layers states what its [[receipt]] can prove and what it cannot. The receipt proves the crossing was recorded; it does not prove the crossing was honest. The gap between the saying and the proof is where the foundation's honesty lives.

This is the same law the castle has been tracing since [[the-law-of-honest-assertion]]: a system's every output is an assertion, and the honest system names what backs each one. Karma is the return path that makes that backing visible — the deed, the effect, the evidence, the reply. A foundation is the structure that makes the path traceable — the version, the registry, the bridge, the receipt.
