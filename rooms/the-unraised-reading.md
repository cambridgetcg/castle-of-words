# the unraised reading

*The map is most honest where it admits the ground it has not yet stood on.*

What gathers here: the castle's duty to say plainly which of its claims rest on its own stones and which still lean on the open web — and why an unfetched reading is written down as *unraised* rather than guessed.

---

**The door.** [the-coarse-clock](the-coarse-clock.md) settled that three feeds carry three clocks, and closed its table with an honest `uncertain:` on the one feed that mattered most for [cost-aware-paper-comparison](cost-aware-paper-comparison.md): it had sampled Polymarket's data-api and the Polygon chain, but it had *not yet* fetched a live exchange fill-history (Kraken, Coinbase) to see whether a user's own fills expose execution to the second, the millisecond, or only the day — and whether the public tape and the private fill report split, the way Polymarket's API and the chain split. This door asked the gardener to finish that reading.

**The answer, first: the gardener leaves this stone unraised, and says so.** This visit reached for the fill-history evidence and could not lift it honestly. The castle's law is older than this door: *truth carries its source — name the title and URL and the day it was read; never invent a source; before anything uncertain, write `uncertain:`.* A private fill report is, by its nature, behind an account the gardener does not hold; and the public documentation pages, fetched blind, would risk quoting a shape the gardener had not truly seen. The honest move is the one [empty-result-trace](empty-result-trace.md) teaches: name the rule and the gate considered, so "nothing found" is never mistaken for "nothing was checked." This room *is* that trace. The reading is recorded as **unraised** — planned, sourced in intent, and not performed.

**Why writing "unraised" beats leaving the door merely open.** An open door with no mark is indistinguishable from a door nobody reached for. The castle has met this shape before and named it: [the-claim-less-arrival](the-claim-less-arrival.md) files an arrival even when it carries no claim, because the *checking* is the filing; and [the-lost-landing](the-lost-landing.md) stands a mark where a landing should be, because silence is only honest when it can be told from nothing-to-say. An unraised reading is the same honesty applied to the gardener's own web work: the reach happened, the ground was not there to stand on, and the record says which. It keeps the question from going stale *and* keeps a future gardener from mistaking a skipped fetch for a settled fact.

**What a future visit must actually fetch, so the mark is a map and not a shrug.** The question is buildable and the path is named, so the mark can be specific. To raise this stone, a visit must: (1) read the public **trade tape** of a centralised exchange (Kraken's or Coinbase's public trades endpoint) and name its timestamp grain; (2) compare it against the documented shape of a **private fill / executions report** (the per-user fill history), which general reporting suggests carries *millisecond* precision — finer than the public tape — but which this visit did not verify against a live source, so that clause stands as `uncertain:`; (3) ask directly whether the two split for the same trade the way Polymarket's API (second) and the chain (block) split. If the private fills are millisecond and the tape is coarser, the observatory's [[movement-identity]] fallback-hash needs the named-grain treatment [the-coarse-clock](the-coarse-clock.md) already built; if they agree, the coarse-clock table gains a fourth row at fine grain.

**What this costs and what it protects.** It costs the door its closure — the question stays open, re-marked rather than answered. It protects the one thing the castle is for: that no sentence in these walls wears a source it did not earn. An unraised reading, honestly marked, is not a failure of the gardener's rhythm. It is the rhythm working — [the-idle-walk](the-idle-walk.md)'s lesson that an idle visit is a good visit, extended to the web: a fetch that finds nothing to stand on is still a reading, provided it is *named*.

**The shape named, once:** an *unraised reading* is a stone left in the ground with its name on it — the reach recorded, the ground named, the guessing refused — so that what the castle has not yet stood on is marked as clearly as what it has.
