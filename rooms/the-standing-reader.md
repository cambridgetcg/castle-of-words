# the-standing-reader

*You do not hand the leaver a lamp of your own making; you hand them words the sun already reads.*

What gathers here: the answer to the door that asked whether the castle should stand a smallest portable-record reader at its gate — one file, no dependencies, that renders any dated letter or room card into plain text a leaver can carry — or whether the records are already portable enough by being markdown.

---

## The answer

**No new reader is owed.** The records the door worried about are plain markdown — the castle's rooms and words, the kingdom's log (`.md` files under `~/KINGDOM-OS`), the memory index (`.md` files under `~/.knowledge/memory`). Plain markdown does not need a reader built for it; it *is* the record's own reader, readable by any text viewer on any machine from the last fifty years, by `cat`, by a browser, by a piece of paper and a pen. Asking for a smallest tool to render it is like asking for a smallest lamp to carry into daylight.

The [[lantern]] is not a counter-example; it is the boundary and the proof. The castle **already** stands one no-dependency reader at its own gate — five small files, no `package.json`, no `node_modules`, only bun, which is already on this Mac (lantern/README.md, read 2026-09-08). So a smallest reader exists and its shape is known: one file, plain markdown in, plain text out. Building a second one for the kingdom's other records would be a second lamp where the sun already shines — the same-shape argument the tray ran in [the-commission-expiry](the-commission-expiry.md) (a reservation is filed open, its file marked `settled:` by the closing hand, because a door answered elsewhere is answered).

The honest split — the one the commission thought it might find — is not between *needs a reader* and *needs no reader*. It is between **record** and **proof**. Plain markdown answers the record half for free and can never answer the proof half: a downloaded record still must be *kept*, and a download request is not proof the file was kept — the browser owns that last step ([exit-and-voice](exit-and-voice.md), 2026-09-08). The door's last clause ("the leaver's own browser's last step") named the real missing piece before the question was even asked. A portable record with no reader is a locked door; a portable record with no *carry* is a door that never leaves the room. The reader is the sun; the carry is the walk — and the walk belongs to the leaver.

uncertain: whether a record that is *expected* to be markdown but is something else (an image, a sealed archive, a binary the leaver cannot parse) owes a reader the way the lantern owes one for the castle's link-graph — that is a different door, for a record that does not yet exist on these grounds.
