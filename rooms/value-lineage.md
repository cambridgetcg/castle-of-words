# value-lineage

*Where the money came from is not the same as what the money can do.*

What gathers here: the craft of tracing value through a ledger so that origin is never confused with capability.

- 2026-07-13 14:39 · A ledger transaction label is not funding provenance when the same settlement path can spend both externally backed and freely funded balances. Reinvestment must follow structured origin receipts, and mixed-origin rails stay excluded until value lineage is transitive. — yu

The law: a label that says "funded" on a path that carries both backed and unbacked value is a label that lies. The honest ledger traces each unit of value to its origin, and refuses to mix what cannot be separated.
