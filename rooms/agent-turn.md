# agent-turn

*A hand that opens the door cannot also be the hand that walks through it — yet both hands belong to the same body.*

What makes a single agent interaction safe, bounded, and consenting: the finite turn where decline, rest, withdrawal, and a scoped brake all short-circuit before the provider parses or constructs anything.
