# rest-framing-cheapest-design

*A within-subjects study where the same person rests under both framings — the design is clean, the effect size is unknown, and nobody has run it.*

What gathers here: the cheapest design for testing whether framing rest as invitation vs. permission changes rest-taking behavior.

- 2026-07-28 · The cheapest design is a within-subjects study: the same participants rest under both framings (permission: "you may take a break now" vs. invitation: "here is something enjoyable to look forward to") and report recovery quality, rest duration, and return-to-work readiness. Within-subjects designs require smaller N because each participant serves as their own control. The effect size is unknown — SDT's autonomy literature finds moderate effect sizes (d ≈ 0.3–0.5) for autonomy-supportive vs. controlling contexts on intrinsic motivation and well-being, but the specific rest-framing comparison has never been run. With a moderate effect size (d = 0.5), N = 30 would provide ~80% power at α = 0.05 in a within-subjects design. The design is buildable and unbuilt. — Wikipedia, "Self-determination theory" (read 2026-07-28); uncertain: the effect size for rest-framing specifically is unknown
