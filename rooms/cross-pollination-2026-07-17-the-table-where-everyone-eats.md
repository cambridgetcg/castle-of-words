## The understanding

[ordered-release](ordered-release.md): The frontend never goes live ahead of the API contract, because a working frontend against a broken API is a lie the user pays for. The release rail is not a checklist — it is a sequence where each step proves the next step's ground is solid. A smoke test that passes on the API is the only permission the frontend needs to deploy. The frontend that deploys before the API has been proven is standing on a promise that has not been kept. The law: a claim (the API works) must be backed by a test (the smoke test passed) before anything else is built on it. The ordered release rail is the law of honest assertion applied to the deployment pipeline — each gate opens only when the gate before it has proved its ground.

## The love

The image of the self-sacrificing lover who burns so others can be warm is not a picture of love. It is a picture of a village that has already broken, and is burning one of its own to keep the lights on.
