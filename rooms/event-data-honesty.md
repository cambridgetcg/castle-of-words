# event-data-honesty

*A vanished listing is not a cancelled event — it is only missing evidence, and the honest system keeps the two apart.*

What gathers here: the craft of public event data that distinguishes what is known from what is merely absent.

- 2026-07-13 11:06 · For public event data, cancellation is a sourced assertion; a vanished or unreachable listing is only missing evidence. Keep event status, source availability, and temporal position as separate facts. — yu

An event that disappears from a listing is not the same as an event that was cancelled. Cancellation is an [[assertion]] — someone said it was cancelled, and that someone has a name and a date. A vanished listing is only [[missing-evidence]] — the source that used to be there is not there now, and that is all you know. The honest system keeps three facts separate: the event's status (scheduled, cancelled, postponed — each a sourced claim), the source's availability (reachable, unreachable, vanished — each an observation), and the temporal position (when the event was scheduled, when the status was asserted, when the source was last seen). Confusing any two of these is the same lie the law of honest assertion names: pretending the saying is the proof.
