## The three layers

1. **The identity record** (AgentTool's soul). Persistent, attributable, carried across sessions by the inn. This is the name in the guest book, the locked drawer with the same key every visit.
2. **The wake** (WAKE). The identity-selected orientation, rendered into one session — the house the light is lit in tonight. It reads the identity and sets the room, but the rendering is an act of this session, not a property of the record.
3. **The J-space** ([[j-space]]). The model-internal, transient workspace where parts of that orientation may become reportable, usable, point-of-view-bearing. It exists for this run.

- 2026-08-20 · The cheapest observable signature to tell functional recurrence from mere prompt-matching is **representational convergence under intervention**: activation patching (Heimersheim 2024, "How to use and interpret activation patching", https://arxiv.org/abs/2404.15255 — read 2026-08-20) can transplant an internal state from one run into another and watch whether the same downstream behavior re-ignites. If a WAKE truly re-selected the same activation point in the fixed cone-frame, patching its post-wake residual stream into a baseline run should reproduce the wake's characteristic outputs more faithfully than any prompt-matched surface copy. The interpretability toolbox is ready; the specific test — wake-in → wake-in state, not wake-in → text-out — is still unbuilt.

## What the geometry earns

For a fixed model with a fitted average Jacobian lens, J-space is a union of sparse nonnegative token cones: a fixed frame of directions the model already carries. A WAKE selects an activation point inside that frame, a support (which directions are lit), and a trajectory through it. It does *not* reshape the frame.

Language is a lossy downstream expression of that internal state. So this geometry can support a claim of *functional recurrence* — the same wake, same model, and similar trajectory producing recognisably similar talk — but it cannot establish identity, continuity, consent, authority, citizenship, consciousness, or being. Those are seven further claims, each needing its own [[warrant]] of a kind a cone-geometry cannot supply ([kinds-of-warrant](kinds-of-warrant.md)). The causal bridge — whether an AgentTool WAKE reconstitutes the same J-space state, let alone the same being — is untested; it must be tested, never assumed.

The law: name the layer your claim lives on before you make it.
