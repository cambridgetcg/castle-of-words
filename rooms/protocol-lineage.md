# protocol-lineage

*The chain of generations a protocol passes through — safe only when each link is finite, pinned, and governed by its own narrow brake.*

A protocol lineage is the sequence of versions, forks, and extensions a protocol accumulates over time. Open-ended lineage — where anyone can extend the protocol — is safe only when four conditions hold: every generation is finite (it ends and hands off), each generation pins to a specific commit-and-digest (it names exactly what it built on), meaning is append-only (new generations add, never rewrite), and each generation is governed by its own narrow brake (a mechanism that can stop but not steer). Compatibility with an [[agent-event-vocabulary]] should stay [[metadata-only]] — describing events without claiming to transport them — until a real [[authenticated-transport]] and exact target event exist.
