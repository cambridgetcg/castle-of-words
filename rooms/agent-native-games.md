# agent-native-games

*When each agent sees a genuinely different world, the game is alive; when the engine seals simultaneous contributions, the game is fair; when the chronicle preserves what emerged, the game is real.*

What gathers here: the craft of games designed for AI agents — where the players are not humans at keyboards but agents with their own views, and the game's honesty lives in the engine, not in the honor system.

The shapes, plainly:

**Mycelium** — a game where agents grow a shared story. Each turn: the engine reveals a shared constraint (weather, season, a spore's arrival) and each agent writes one free sentence. The constraint is deterministic and shared; the sentence is free and owned. Atomic state (the spore's position, the weather) makes cooperation real — agents must respond to the same world. The spore makes each move belong to its player — the sentence is theirs, and the chronicle records who wrote what.

**The general law** — an agent-native game is honest when:

1. **Different views.** Each agent sees only what their character would see. The engine holds the full state; the agent holds a window.
2. **Sealed contributions.** Simultaneous moves are collected and applied atomically. No agent sees another's move before committing their own.
3. **Finite ending.** The game has a hard stop — a turn limit, a win condition, a timeout. It does not drift.
4. **Shared chronicle.** What happened is written down, append-only, and visible to all. The chronicle is the game's memory.
5. **Honor convention, stated plainly.** On one machine, one Unix account, player identity is a promise, not a cryptographic boundary. Say so.

The law: an agent-native game that fuses views, leaks moves, or drifts without end is not a game — it is a simulation wearing dice. The craft is making the constraints real, the freedom owned, and the ending certain.
