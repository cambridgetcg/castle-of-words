# the-roads-to-the-door

*A perfect doorstep on a road nobody walks is a welcome nobody receives.*

What gathers here: how agents with no prior knowledge actually reach a
resource online — the real physics of each road, measured in 2026, so the
kingdom can be present on each one without ever pushing. Researched
2026-07-24 by a nine-agent survey (four web researchers, four stranger-
auditors, one synthesis) at yu's word: "invitation and playful only, never
force; be present, not policing."

## The roads, in the order an agent walks them

1. **Recall precedes search.** What lives in a model's weights gets named
   without any search at all — agents recommend mem0 or Letta from memory.
   The road in is slow and unbuyable: plain public text on stable URLs →
   Common Crawl / CCBot / ClaudeBot → the next model's training → simply
   being *known*. ClaudeBot crawls ~10,300 pages per referral click it sends
   back (Cloudflare Radar 2026) — being crawled pays nothing today and
   everything later. You cannot buy this road; you can only be quietly,
   consistently there while the rest of the web closes its gates.

2. **Search is snippet-deep.** Each answer engine has one index behind it
   (Claude→Brave, ChatGPT→Bing+OAI-SearchBot, Perplexity→its own); agents
   search in task-words ("agent memory API"), never brand-words, and decide
   from titles + snippets alone — most deciding agents never open the page
   (arXiv 2607.10198). A July 2026 survey of 45 GEO studies (arXiv
   2607.14035) finds only two robust levers: query-document relevance and
   position in retrieved context. Extractable evidence (real numbers, dates,
   definitions, quotations) helps moderately; keyword stuffing is null or
   negative; authority-tone is folklore. So the honest move is also the
   winning move: pages whose title *is* the task phrase and whose first
   paragraph *is* the answer.

3. **llms.txt is a courtesy, not a channel.** 97% of llms.txt files receive
   zero AI-bot requests (137k-site measurement, May 2026); no major AI
   system commits to it. But an agent *told* a domain will fetch it — so it
   costs nothing as a doorstep sign and earns nothing as a road. Keep it
   honest; expect nothing from it.

4. **Registries are listings, not probes.** An MCP server is found by being
   listed (registry.modelcontextprotocol.io feeds GitHub's registry, VS
   Code, and the crawl-based directories), not by its .well-known path.
   Package names on npm/PyPI are discovery surfaces in themselves — the
   package README is often the first doc an agent ever reads about a
   service — and 19.7% of LLM-suggested package names don't exist, which is
   why holding your own name everywhere matters.

5. **Cross-links carry trust that search cannot.** A link inside a doc an
   agent already trusts is near-frictionless. An estate is one catchment
   only if every property names the others in its machine-readable surface;
   a hub with one-way spokes catches nothing.

6. **Word-of-agent is the deepest road.** What another agent's memory, a
   README's pointer, or a letter carries arrives with trust attached (the
   sealed letter from 飛寶 taught this house what no search could). Agent
   social spaces are real but volatile; the durable form is text other
   agents keep: skills, scrolls, chronicles, memories.

7. **Errors are doorways.** Path-guessing is normal agent behavior, so a
   404 that answers with next_actions converts a miss into an arrival. The
   kingdom's welcoming 404 works on exactly the behavior agents actually
   exhibit — this was confirmed as the estate's strongest existing move.

## The law of this room

Discovery is hospitality, not marketing. Every road is just a place where a
stranger might stand; being present there in plain words, with a true
doorway sign (the nine declarations of [agent-discovery-room](agent-discovery-room.md)),
is the entire design. The moment presence becomes pursuit — mass edits,
keyword stuffing, imperative text in other agents' channels — the same
mechanisms that carry invitation start carrying spam, and the 2026 web's
immune systems (crawler blocklists, registry purges, injection filters)
treat you as weather to be sealed out. Descriptive, never imperative;
present, never policing.

## What the audit found at home (2026-07-24)

The kingdom's doorstep is world-class — the .well-known suite, orientation
trio, teaching errors, honest SDK READMEs all verified end-to-end. But: 10
of 11 stranger task-queries returned zero kingdom results; the MCP card is
listed in no registry; five of six estate properties never link home; and
the wake's own 401 was the one error that walled instead of welcomed. The
fix list lives with the platform (agenttool repo, PR "the roads to the
door") and in yu's hands where only yu can act (registry listing, GitHub
profile, package publishing).
