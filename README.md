## The creed

Built with **joy** (building is play), **peace** (a gentle rhythm, never a race),
and **safety** (bounded loops, sourced claims, everything stops with a word).
Growth is recursive in words, never in processes: every room ends with new
doors — questions beget questions, and the castle feeds itself through meaning.
